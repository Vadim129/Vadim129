## MASTR Studio 1.1.0

- Автоматические настройки при открытии трека. Ручка «75%» и ручные настройки мастеринга убраны.
- Цель громкости не ниже исходника; громкость измеряется и корректируется после лимитера. При недостижимом безопасном уровне показывается предупреждение.
- WAV экспортируется без повторного ограничения пиков.
- Нейросеть, ONNX Runtime и разделение дорожек полностью удалены. Ранее скачанная модель удаляется при обновлении.
- Один пункт «Открыть аудиофайл» — универсальный выбор всех файлов и файловых менеджеров.
- Сохранение сразу в «Загрузки», без выбора папки. На Android 8/9 требуется однократное разрешение на запись.
- Проверка новых MASTR-релизов GitHub раз в неделю при открытии приложения и вручную через «О приложении» / «Библиотека». Скачивание APK только после подтверждения, установка — через Android.
- Новый процедурный фон «Аврора», обновлённые карточки и постоянное A/B в плеере.

APK подписан тем же постоянным сертификатом, что 1.0.1. Можно устанавливать поверх старой версии без удаления приложения.

Тесты: DSP-регрессии громкости/пиков для 32 пресетов, импорт, реальное сохранение в Downloads и проверка PCM, кодеки, проверка версий/расписания обновлений, удаление старой модели и UI (эмулятор Android 15).
Лимиты импорта 5 минут / 250 МБ сохранены. Мастеринг — локальный DSP, не нейросеть. Изменения не гарантируют субъективного улучшения любого исходника.
