# Перекрас

Приложение для Android, которое даёт приложениям свои значки: одна форма, одна палитра,
свои обои — без рута и без «тем» из магазина.

| | |
| --- | --- |
| Имя | **Перекрас** |
| Пакет | `com.perekras.app` |
| Минимальная версия | Android 8.0 (API 26) |
| Разрешения | никаких |
| Размер APK | ~110 КБ |

![Иконка](docs/icon-512.png)

## Что делает

* **Одна тема на все значки.** Выбираешь форму (квадрат, круг, «самсунг»), палитру из восьми
  наборов цветов и обои — и все значки получают один вид.
* **Перекраска по приложениям.** Отмечаешь приложения в списке — приложение кладёт на рабочий стол
  готовые значки. Рабочий стол спрашивает подтверждение: это штатное поведение Android
  (`ShortcutManager.requestPinShortcut`), другого способа положить значок на стол, не будучи
  лаунчером, в системе нет.
* **Своя картинка вместо значка.** Можно выбрать любую картинку из галереи и поставить её
  приложению.
* **Обои.** Три набора в комплекте плюс своя картинка из галереи.
* **Собственная панель (полный режим).** Если выбрать «Перекрас — рабочий стол» домашним
  экраном, все приложения показываются сразу в одном стиле и на обоях, без закрепления
  по одному. Панель можно просто открыть и посмотреть, ничего не меняя.

## Чего приложение не делает (честно)

Android не разрешает обычному приложению подменить значки *чужих* приложений в штатном
лаунчере. Перерисовывать все значки сразу умеют только производители (Samsung, Xiaomi и т. п.):
у них для этого есть системный компонент-«помощник значков», которого на обычном телефоне нет.
Поэтому здесь два рабочих пути, описанных выше: ярлыки в вашем стиле и своя панель.

## Где взять APK

Собранный файл лежит в ветке `perekras-apk` этого репозитория (файл `perekras-*.apk`)
и в GitHub Releases с тегом `perekras-*`. Установка: скачать на телефон, открыть,
разрешить установку из этого источника.

## Сборка своими руками

```bash
cd perekras
gradle assembleRelease        # нужен JDK 17 и Android SDK (compileSdk 35)
# результат: app/build/outputs/apk/release/app-release.apk
```

Подпись своим ключом делается в CI: положи в секреты репозитория
`PEREX_KEYSTORE_B64` (keystore в base64), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` —
и APK будет подписан вашим ключом вместо отладочного.
Workflow: `.github/workflows/perekras-apk.yml`.

## Устройство проекта

```
perekras/
  app/src/main/
    AndroidManifest.xml          активити, приёмник подтверждения ярлыков, <queries>
    java/com/perekras/app/
      MainActivity.java          выбор формы/палитры/обоев, применение ко всем ярлыкам
      AppsActivity.java          список приложений с поиском и отметками
      FloatingHome.java          собственный рабочий стол (ACTION_HOME)
      PinReceiver.java           узнаёт, что ярлык добавлен на стол
      Styler.java                отрисовка значка: маска формы + цвет палитры, кэш
      Style.java                 палитры, формы, хранение оформления
      Apps.java                  список приложений, ярлыки, запуск
      Media.java                 импорт своих картинок внутрь приложения
    res/                         иконки всех плотностей, строки, темы
    assets/walls/                обои, нарисованные кодом
  tools/gen-icons.py             генератор иконок приложения (без библиотек)
  tools/gen-walls.py             генератор обоев
  docs/icon-512.png              превью иконки
```

Иконки и обои нарисованы кодом — в репозитории нет «магических» бинарников
неизвестного происхождения.
