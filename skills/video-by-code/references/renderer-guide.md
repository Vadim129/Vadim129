# Устройство рендерера и как его менять

`scripts/render.py` — один файл, ноль внешних ассетов кроме шрифтов
(`assets/fonts`, Montserrat + JetBrains Mono, OFL 1.1). Внутренний холст
всегда 1080×1920; `width/height` конфига применяются масштабом при кодировании.

## Поток

`main()` читает JSON → считает кадры сцен (`duration × fps`) → покадрово
вызывает строитель сцены (`BUILDERS[type]`) → накладывает оверлей →
пишет raw-кадры в ffmpeg (libx264) → синтезирует звук (`make_soundtrack`)
→ склеивает в `output` +faststart.

Каждый строитель: `sc_*(scene_cfg, frame_global, local, length_frames, meta)`.
Внутри сцены время всегда нормировать (`p = local / length`), а не писать
«кадр 32» — тогда сцена переживает любую длительность.

## Что менять под задачу

| Надо | Где |
|---|---|
| Тексты, автор, палитра, длительности | только JSON-конфиг, код не трогать |
| Честное число строк кода | `counter.value: "auto"` — считается при рендере |
| Другой темп/без звука | `audio.bpm`, `audio.enabled`, флаг `--no-audio` |
| Черновик для проверки | `--preview` (360×640, та же длительность и звук) |
| Новый цвет фона текстовой сцены | `big_text.bg`: black/accent/light/grid/code |

## Новая сцена (если библиотечной не хватило)

1. Функция `sc_имя(s, frame, local, L, meta)` по образцу соседних:
   easing `ease_out/ease_inout/pop`, появление через `slide`/`pop`,
   текст — только через `fit()` (подгон под ширину) и `center_text()`.
2. Зарегистрировать в `BUILDERS` и, если фон светлый, в `LIGHT_TYPES`
   (иначе оверлей будет белым по светлому).
3. Добавить строку в таблицу в `references/scenario-format.md`.
4. Проверка: `--preview`, раскадровка, отдельный кадр середины сцены
   в полном размере (текст не обрезан? кириллица не «квадратами»?).

## Производительность и грабли

- Полный рендер 15 с / 450 кадров на CPU — около минуты; частицы и куб —
  самые дорогие сцены. Кэши текстур куба и целей частиц уже стоят
  (`_cube_cache`, `_particle_cache`) — не убирать.
- Куб: перспектива считается `_coeffs` (выход→вход для PIL PERSPECTIVE).
  Перепутать порядок аргументов — грани «схлопываются» в трапеции.
  Рёбра рисовать после всех граней, иначе заливка их перекрывает.
- Частицы: цели сэмплить из маски текста тем же шрифтом, что подпись сцены,
  иначе «честное число» частиц разойдётся с кадром.
- Звук: бит строится до `finale_at` (старт последней finale-сцены),
  на каждой границе сцены — удар-свип, перед финалом райзер, в финале аккорд.
  Нет finale-сцены — бит идёт до конца, райзера/аккорда нет.
- Оверлей: TC считается от номера кадра; при смене fps не ломается,
  но формат рассчитан на ролики < 1 часа.
- Шрифты без кириллицы = «квадраты» в кадре. Подходит любой тяжёлый гротеск
  с кириллицей (Montserrat 900 в комплекте); моноширинный — для служебки.

## Зависимости

`pip install Pillow numpy imageio-ffmpeg` — ffmpeg берётся из пакета,
системный не нужен. Проверка окружения: `python3 -c "import imageio_ffmpeg"`.
