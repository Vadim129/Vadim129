# Проверка результата (QA)

Без этого чек-листа ролик пользователю не отдавать.

## Автоматика — `scripts/verify.py КЛИП --expect config.json`

- длительность = сумме сцен (±0.15 с);
- размер и fps = конфигу;
- звук есть, mean-громкость не ниже −30 dB, пик ≤ 0 dB;
- рядом ложатся `раскадровка.png`, `обложка.png`, `отчёт.json`.

## Глазами — по раскадровке и 3–4 полным кадрам

1. **Каждая сцена читается за свою долю секунды:** главный текст влезает,
   не обрезан краями, не налезает на оверлей (REC/TC/SC целы и читаемы).
2. **Границы сцен:** есть акцент (глитч/вспышка/удар), нет «провалов»
   в пустой фон дольше 3–4 кадров (кроме намеренной паузы перед финалом).
3. **Кириллица** не квадратами; кавычки/тире/«•» на месте.
4. **Честные числа:** счётчик доходит до кадров ролика, частицы соответствуют
   подписи, «строк кода» = реальным строкам рендерера.
5. **Финал держится** ≥1 с в собранном виде (успевает прочитаться),
   прогресс-бар внизу к концу полный.
6. **Звук:** удары совпадают со склейками, в финале бит стихает,
   концовка не обрывается щелчком (fade 0.25 с стоит в рендерере).

## Поставка

- Главный файл: mp4 (H.264 yuv420p, AAC 192k, faststart) — открывается везде.
- Пользователю: сам клип (present), одной строкой — допущения
  (подпись, длительность), рядом лежат раскадровка/обложка/отчёт.
- Если пример пришёл с Диска — аналог загрузить в ту же папку.
- Код и конфиг — в репозиторий, если работа идёт в нём; тяжёлые промежуточные
  (`_silent.mp4`, черновики) в коммит не тащить.
