# Разбор видео-примера

Цель разбора — не «переснять кадр в кадр», а понять конструкцию:
ритм склеек, набор эффектов, палитру, сквозные элементы. Тексты,
подпись и формулировки в аналоге меняются (см. SKILL.md, шаг 3).

## Процедура

1. Прогон `scripts/analyze.py ВИДЕО --out анализ-ИМЯ`:
   - `probe.json` — длительность, размер, fps, есть ли звук и его громкость;
   - `frames/` — кадры 1/сек, `contact_1fps.jpg` — вся раскадровка одной картинкой;
   - `spectrogram.png` — ритм звука: удары, паузы на склейках, финальный аккорд;
   - `cuts.json` — машинные кандидаты на склейки (проверить глазами, не верить слепо).
2. Посмотреть `contact_1fps.jpg`, затем точечно кадры вокруг каждой склейки
   (±0.5 с с шагом 2–3 кадра, `ffmpeg -ss`) — на границах живут глитчи,
   вспышки и смены подписей, которых не видно на секундных кадрах.
3. Заполнить таблицу в `АНАЛИЗ-черновик.md`:
   - текст на экране — **дословно**, с регистром и переносами;
   - эффект: как появляется/исчезает (въезд, pop-пружина, частицы, счётчик…);
   - фон и акцентный цвет (hex примерно по кадру);
   - сквозной оверлей: углы REC, таймкод, SC-счётчик, прогресс, подпись автора.
4. Звук: темп (считать удары по спектрограмме), есть ли акценты на склейках,
   чем заканчивается (аккорд/затухание). Точность ±10 BPM достаточна.

## Разобранный пример (эталон оформления)

Оригинал `VID_20261016_130422_134.mp4`: 15.00 с, 1080×1920, 30 fps, звук есть.

| № | Время | Текст | Эффект |
|---|---|---|---|
| 1 | 0.0–1.8 | «ЭТО НЕ ВИДЕО. ЭТО КОД» + счётчик строк | бегущий код на фоне, строки въезжают |
| 2 | 1.8–3.6 | «ДВИЖЕНИЕ» вертикально | оранжевый фон, кинетическая типографика |
| 3 | 3.6–5.4 | грани куба: 3D/ТИПОГРАФИКА/ЗВУК/ЧАСТИЦЫ | вращающийся 3D-куб |
| 4 | 5.4–7.2 | «15 СЕКУНД» | частицы: вспышка → текст → разлёт |
| 5 | 7.2–9.0 | счётчик → «450 КАДРОВ» | цифры + эквалайзер |
| 6 | 9.0–10.8 | «БЕЗ ПЛАГИНОВ» → «ТОЛЬКО КОД» | вращающаяся геометрия, стикеры |
| 7 | 10.8–12.6 | «SHOW REEL» | светлый фон, инверсия в конце |
| 8 | 12.6–15.0 | «CLAUDE / MOTION • CODE • SOUND» | финал на чёрном |

Сквозное: ●REC, TC-таймкод справа сверху, SC xx/08 + прогресс снизу,
палитра чёрный/кремовый/оранжевый, жирный гротеск + моноширинный для служебки.

## Типичные ловушки

- Секундные кадры пропускают короткие вспышки/инверсии — смотреть границы сцен плотно.
- Счётчики и «честные числа» (строки кода, частицы, кадры) в аналоге пересчитывать,
  а не копировать: кадры = длительность × fps, частицы = параметр сцены и т.д.
- Подпись автора оригинала не переносить в аналог — ставится подпись заказчика.
