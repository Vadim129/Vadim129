# Сценарий: свободный текст → JSON-конфиг

Агент принимает сценарий в любом виде: абзац («на 15 секунд, типа смотрите,
как я умею…»), список по секундам, таблицу. Задача агента — нормализовать
его в JSON для `scripts/render.py`, не переспрашивая лишнего.

## Скелет конфига

```json
{
  "title": "Название (для себя)",
  "author": "VADIM",
  "width": 1080, "height": 1920, "fps": 30,
  "output": "клип.mp4",
  "palette": {"bg": "#0A0A0A", "ink": "#F4EDE2", "accent": "#FF5A1A"},
  "overlay": {"enabled": true, "label": "VADIM / MOTION"},
  "audio": {"enabled": true, "bpm": 120},
  "scenes": [ {"type": "...", "duration": 1.8, "...": "..."} ]
}
```

## Библиотека сцен (type → обязательные/главные поля)

| type | Что делает | Поля |
|---|---|---|
| `hook_code` | бегущий код + строки + счётчик-плашка | `lines[]`, `counter{value: "auto"\|число, suffix}` |
| `big_text` | крупные строки на фоне black/accent/light/grid/code | `lines[]`, `bg`, `effect: slide\|pop`, `label`, `footer` |
| `kinetic` | вертикальное слово на акцентном фоне | `word`, `label` |
| `cube` | 3D-куб проекцией, текст на гранях | `faces[4]`, `top`, `label` |
| `particles_text` | частицы собираются в текст | `big`, `small`, `count`, `label` |
| `counter` | счётчик 0→N + эквалайзер | `to`, `suffix`, `label`, `meta[3]` |
| `geometry` | вращающиеся фигуры + стикеры | `stickers[]` |
| `showreel` | светлая сцена, 2 строки, инверсия | `lines[2]`, `sub` |
| `finale` | автор + черта + подписи | `title` (по умолчанию author), `sub`, `extra[]` |
| `tg_intro` | заставка чата: самолёт, название, аватар | `title`, `sub`, `image`, `chat_bg` |
| `tg_chat` | чат с персонажем-фото и пузырьками | `image`, `header{title,sub}`, `bubbles[]`, `image_effect`, `button`, `typing` |
| `tg_outro` | финал чата: логотип + «смотри дальше» | `title`, `text`, `image` |

Строка в `lines` — либо `"ТЕКСТ"`, либо `{"text": "ТЕКСТ", "color": "accent"}`.
Цвета: `ink` (основной), `accent`, `bg`. Шрифт подберётся под ширину кадра
автоматически (`fit`), но строки длиннее ~12 символов в крупном кегле
лучше разбивать на две.

## Правила нормализации

1. **Длительность.** Не задана — брать из примера; нет примера — 15 с.
   Сцены по умолчанию равные (1.6–2.0 с), финал чуть длиннее (2.2–2.5 с).
   Сумма `duration` обязана давать целевую длительность (±0.1 с).
2. **Подпись/автор.** Из слов пользователя, имени аккаунта/репозитория.
   Не угадывается — спросить одним вопросом; подпись оригинала не копировать.
3. **Тексты.** Формулировки пользователя сохранять дословно; если дана только
   идея («покажи, что умеешь») — предложить 5–9 коротких строк в том же тоне.
4. **Числа должны быть честными:** `counter.to` = кадры ролика (сек × fps),
   `particles_text.count` = реальное число частиц сцены,
   `counter.value: "auto"` в hook_code = строки самого render.py.
5. **Палитра.** Из примера (3 цвета: фон/текст/акцент) или дефолт
   чёрный `#0A0A0A` / кремовый `#F4EDE2` / оранжевый `#FF5A1A`.
   Акцент должен читаться и с чёрным, и с кремовым текстом.
6. **Звук.** По умолчанию включён, 120 BPM; темп из разбора примера ±10.
   Для чат-роликов: `"audio": {"style": "chiptune", "bpm": 132, "music_volume": 0.5,`
   `"events": [{"at": 0.25, "type": "ping"}, {"at": 6.1, "type": "boom"}],`
   `"voice": [{"file": "voice/01.mp3", "at": 2.3, "gain": 1.6}]}` — события:
   ping/pop/boom/hiss/click/whoosh/pulse/chord; voice — готовые реплики
   (путь от конфига), `music_volume` приглушает фон под голосом.
   Реплики готовить «пиксель-голосом»: rubberband tempo×1.4–1.5 pitch×1.2 +
   acrusher 7 бит + обрезка тишины; старт реплики = появлению её пузырька ±0.3 с.

## Когда спрашивать, а когда делать

- Спрашивать (одним сообщением, ≤3 вопросов): имя/подпись, если нигде не
  встречается; целевую длительность, если не задана и нет примера;
  площадку (вертикаль/горизонталь), если неочевидна.
- Не спрашивать: шрифты, темп, число частиц, оформление оверлея — это
  решается по примеру или дефолтам, в отчёте одной строкой указать допущения.

Готовые образцы: `examples/scenario-showreel.json` (аналог разобранного
примера) и `examples/scenario-demo.json` (другой сценарий, автор и палитра).
