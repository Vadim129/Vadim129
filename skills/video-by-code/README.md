# Скилл `video-by-code` — видео кодом по примеру или сценарию

Агентный скилл: загружаете пример видео (или пишете сценарий текстом) —
агент разбирает его покадрово и рендерит аналогичный ролик **полностью
кодом**: Python (Pillow + NumPy) рисует каждый кадр, синтезирует звук,
ffmpeg собирает mp4. Без видеоредактора, плагинов и готовых футажей.

Родился из ролика «Смотрите, как я умею» (`showreel/` + `out9/` в этом
репозитории) — обобщённая версия того же рендерера.

## Как пользоваться

Просто попросите агента, у которого подключён скилл:

> Вот пример видео [файл/ссылка на Диск]. Сделай аналог на 15 секунд,
> подпись — VADIM, заход: «Смотрите, как я умею».

или без примера, одним сценарием:

> Сделай видео кодом на 9 секунд: 0–2 — «ДЕЛАЮ ВИДЕО КОДОМ» на фоне кода,
> 2–4 — частицы собирают «9 СЕКУНД», 4–6 — счётчик кадров,
> потом «БЕЗ МОНТАЖА / ТОЛЬКО КОД» и финал с подписью ANNA.

Агент сам: разберёт пример (`scripts/analyze.py`), составит таблицу сцен,
соберёт JSON-конфиг, отрендерит черновик, проверит (`scripts/verify.py`)
и отдаст mp4 (+ раскадровку и обложку).

## Установка скилла

Скопируйте папку `skills/video-by-code` туда, где ваш агент ищет скиллы, —
например, в `~/.claude/skills/video-by-code` или в `.claude/skills/` проекта
(для агентов, читающих `.agents/skills`, в этом репозитории уже лежат
указатели в `.claude/skills/video-by-code` и `.agents/skills/video-by-code`).
Зависимости: `pip install Pillow numpy imageio-ffmpeg`.

## Что внутри

| Путь | Зачем |
|---|---|
| `SKILL.md` | Инструкция агенту: режимы входа, процесс, жёсткие правила |
| `scripts/render.py` | Рендерер: 9 библиотечных сцен + синтез звука, всё из JSON-конфига |
| `scripts/analyze.py` | Разбор примера: кадры, раскадровка, спектрограмма, кандидаты склеек |
| `scripts/verify.py` | Проверка клипа: спеки, громкость, раскадровка, отчёт |
| `references/` | Методички: разбор, формат сценария, устройство рендерера, QA чек-лист |
| `examples/` | Два готовых конфига: шоурил-VADIM и демо с другим сценарием/палитрой |
| `assets/fonts/` | Montserrat + JetBrains Mono с кириллицей (OFL 1.1) |

Библиотека сцен: код-фон с счётчиком строк, крупная типографика,
кинетическое вертикальное слово, 3D-куб чистой проекцией, текст из
2 600 частиц, счётчик кадров с эквалайзером, вращающаяся геометрия
со стикерами, светлый SHOW REEL с инверсией, финал с подписью.
Поверх — «камерный» оверлей: ●REC, таймкод, SC xx/NN, прогресс-бар.

## Проверено на практике (2026-10-16)

- `analyze.py` на исходном примере: спеки, кадры и спектрограмма сняты,
  найдены 5 из 7 склеек-кандидатов (остальные агент добирает глазами —
  так и задумано, машина даёт кандидатов, не истину).
- `render.py examples/scenario-showreel.json`: 15.0 с, 1080×1920, 30 fps —
  воспроизводит ролик из `out9/` (счётчик строк честно пересчитался под
  новый файл: 761).
- `render.py examples/scenario-demo.json --preview`: другой сценарий,
  автор и палитра (ANNA, бирюзовый акцент, 9 с) — работает без правок кода,
  только JSON.
- `verify.py` по обоим роликам: все проверки зелёные.
