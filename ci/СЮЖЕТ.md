# «Честь моя» — сюжет клипа (по тексту песни)

Рисованные кадры цветными карандашами (сгенерированы нейросетью, люди и лица — настоящие, без кривых палочек).
Никаких печатных надписей на экране: всё, что читается, — рукописное, как часть рисунка.
Движок «Чернильный клип» листает страницы по таймингу песни, с легким наездом камеры и переворотом листа.

каждая сцена длиннее 8 секунд; смена кадра — на границе фраз песни.

## Как это собирается

1. `ci/frames/*.jpg` — готовые кадры (в репозитории).
2. `ci/frames.json` — раскладка кадров по времени (эта таблица).
3. `ci/patch_scenes.py` — добавляет в движок функцию `mount(spec)`: она кладёт страницы-картинки по таймингу.
4. `ci/render-photo.mjs` — открывает движок в браузере, отдаёт ему трек и кадры, монтирует таймлайн,
   сохраняет обложку и раскадровку, потом записывает клип в реальном времени и перегоняет в H.264/AAC.
5. `ci/clip2.sh` — вся стадия целиком (её и запускает GitHub Actions по `ci/stage.txt`).
