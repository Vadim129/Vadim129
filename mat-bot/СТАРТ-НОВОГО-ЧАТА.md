# СТАРТ НОВОГО ЧАТА — проект «Мэт» (читать первым делом)

Если ты — агент в новом чате: продолжаем проект вертикальных роликов
бота Мэта. Ничего не выдумывай с нуля, всё уже работает. Сначала
прочитай этот файл и `mat-bot/ПРАВИЛА.md`, глянь последний сценарий
`mat-bot/СЦЕНАРИЙ-*.md` и конфиг `mat-bot/mat-*.json` — и работай
точно так же.

## Что за проект

Мэт — бот с аутизмом (аватарка `mat-bot/assets/robot.jpg`), герой
вертикальных роликов 1080×1920. Пользователь (Слава) пишет задачу в
чат → агент пишет сценарий → голос Мэта → картинки → конфиг сцен →
программа-рендер собирает `клип.mp4` → загрузка на Google Диск (папка
проекта: `1EIafa19ouL52giZGLO2ytrNNRfJkPzMS`) → показать ролик
пользователю (present_file) → коммит и push в этот репозиторий.
Готовые ролики: out11…out28 (по одному на каждую тему).

GitHub здесь — архив и память проекта (сценарии, голос, картинки,
конфиги, код). Видео собирается НЕ на GitHub, а в рабочей среде
рендером. Диск — только витрина готовых mp4.

## Жёсткие правила (нарушать нельзя)

1. **Голос Мэта — только voice-00** в generate_speech, с последующей
   «пиксель-обработкой» (рецепт ниже). Голос не менять НИКОГДА.
   Прослушивания add_voice для Мэта запрещены. Никаких voice-02/03.
   Оценивать по обработанному голосу в готовом ролике.
2. **Одна реплика = одна сцена.** Реплики на половинки не резать.
   Текст в облаке на экране = ровно то, что голос говорит в этот
   момент, целиком. Картинка не меняется посреди реплики.
   (Подробно: `mat-bot/ПРАВИЛА.md`, правило №3.)
3. **Ударения в TTS** задаются знаком ́ (U+0301) СРАЗУ ПОСЛЕ ударной
   гласной (тре́щина — ударение на Е! свети́). ЗАГЛАВНЫЕ гласные
   синтезатор не слышит. В облаках на экране — обычная орфография
   без знаков, знаки только во входе generate_speech.
4. Основная аватарка — всегда `assets/robot.jpg`; дополнительные
   (avatar-exist/piter/crack/glow.jpg) — только тематические вставки.
5. Тон — по задаче. Если просят застебать — жёстко, без «ничьей» и
   дипломатии. Без «Привет, я Мэт» — сразу с сути. Ролик не называть
   «стендапом». Никаких «заходите в чат» ни голосом, ни на экране.
   Мэт — не персонаж чужих клипов, а саркастичный зритель.
6. Чужие видео нельзя комментировать по догадкам: сначала слушать
   аудио (ASR), потом писать текст.

## Конвейер (как делать ролик)

1. Сценарий: реплики Мэта, пишется в `mat-bot/СЦЕНАРИЙ-<ТЕМА>.md`.
   Одна реплика ≈ 8–15 секунд речи; обычно 9–10 реплик на ролик.
2. generate_speech: voice-00, текст со знаками ударения ́,
   файлы в `mat-bot/voiceNN/raw/NN.mp3` (NN — следующий номер папки;
   лимит 10 генераций за ход).
3. Обработка голоса (ffmpeg есть в imageio-ffmpeg), каждый raw →
   `fNN.mp3`: silenceremove −45 дБ с обоих концов →
   rubberband tempo=1.45:pitch=1.22 → acrusher bits=7 → volume=1.12.
4. Конфиг `mat-bot/mat-<тема>.json`, сцены типа pop_stage: заголовок,
   облако с ПОЛНЫМ текстом реплики, стикеры tag-стиля, картинка.
   Сцена = 0.45 + голос + 0.6 с; голос at = старт сцены + 0.45,
   gain 1.45. Музыка: chiptune, bpm 132, volume 0.35.
   Длинные облака: >240 знаков — картинка 360/cy 1710, облако y=300;
   >195 — 400/1480, стикер1 y≈1335; иначе 520/1390, стикер1 y=1240.
   (Облако в 10+ строк не должно закрывать лицо.)
5. Рендер: `python3 skills/video-by-code/scripts/render.py
   mat-bot/mat-<тема>.json --out outNN`, затем
   `python3 skills/video-by-code/scripts/verify.py outNN/клип.mp4`
   (должен сказать «ИТОГ: ОК»).
6. Обязательно посмотреть 4–5 кадров из ролика (ffmpeg -ss …) и
   проверить: текст не перекрыт, лицо видно, стикеры на месте.
7. Загрузить `outNN/клип.mp4` на Google Диск в папку проекта с
   понятным именем «Мэт — <тема>.mp4», выдать ссылку.
8. Убрать служебные обложка/отчёт/раскадровку из outNN, коммит+push.
9. Показать ролик пользователю через present_file.

Разовые ролики «никуда не записывай» — наоборот: всё в /tmp, только
Диск, в репозиторий ничего не коммитить (так уже делали несколько раз).

## Если окружение «сбросилось»

Платформа иногда пересоздаёт рабочее дерево: тогда
`git fetch && git merge origin/arena/44ea88f2-vadim129` (НЕ
force-push) и `pip3 install --quiet --break-system-packages Pillow
numpy imageio-ffmpeg`. Билдеры конфигов исторически писались в /tmp —
не страшно, конфиг легко пересобрать из сценария по этому файлу.
