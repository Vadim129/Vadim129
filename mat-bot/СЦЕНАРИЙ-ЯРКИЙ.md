# Мэт — яркая версия без окна чата (23 секунды)

Замена первой версии (`out10/`): без интерфейса чата, яркие поп-фоны,
диктор только в начале и в конце, середина — фразы Мэта из предыдущего
видео (те же обработанные «пиксель-голосом» файлы `mat-bot/voice/`).

| Время | Кто говорит | Текст | Экран |
|---|---|---|---|
| 0.0–3.4 | **Диктор** | «Знакомьтесь — бот-аутист Мэт!» | Жёлтый санбёрст, заголовок «ЗНАКОМЬТЕСЬ! / БОТ-АУТИСТ МЭТ», Мэт крупно |
| 3.4–6.0 | Мэт | «Привет! Я Мэт. Я…» | Голубой фон, облако у Мэта, стикер «ЭЭЭ…» |
| 6.0–9.4 | Мэт | «Я люблю котиков, но… А почему небо синее?» | Розовый фон, облако, стикеры «КОТИКИ!», «НЕБО?!», «ПОЧЕМУ??» |
| 9.4–11.8 | Мэт | «Ты не видишь, что я прав?» | Оранжевый санбёрст, «СПОР!», стикеры «БУМ!», «Я ПРАВ!» |
| 11.8–14.2 | Мэт | «Мне не нравится, как это работает!» | Зелёный фон, Мэт пульсирует, «*НОЕТ*», «ВСЁ НЕ ТАК!» |
| 14.2–17.0 | Мэт | «Хочешь пообщаться? Заходи в чат!» | Фиолетовый фон, Мэт подпрыгивает, стикер «В ЧАТ!» |
| 17.0–21.2 | **Диктор** | «Заходите в чат Acid Crunch, чтобы пообщаться с ним!» | Красный санбёрст, «ЗАХОДИТЕ В ЧАТ / ACID CRUNCH» |
| 21.2–23.0 | — | (финальный аккорд) | «ACID CRUNCH / СМОТРИ ДАЛЬШЕ», «МЭТ УЖЕ ПЕЧАТАЕТ ЧТО-ТО СТРАННОЕ…» |

Голоса: диктор — `mat-bot/voice2/narrator/` (01 — начало, 06 — финал,
выбранный пользователем голос, темп ×1.12); Мэт — готовые файлы первого
видео `mat-bot/voice/01–05` («пиксель-голос»: темп ×1.45, высота ×1.22,
биткраш). Фон — чиптюн 145 BPM тихо под голосами, поверх — попы/бумы/
whoosh по сценам. Всё задано в `mat-bot/mat-bright.json`, сцена —
`pop_stage` скилла `video-by-code`.

Пересборка:
```bash
python3 skills/video-by-code/scripts/render.py mat-bot/mat-bright.json --out out11
python3 skills/video-by-code/scripts/verify.py out11/клип.mp4 --expect mat-bot/mat-bright.json --out out11
```
