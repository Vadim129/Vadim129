# Правила проекта «Мэт» (указания пользователя, действуют всегда)

1. **Голос Мэта НЕ МЕНЯТЬ НИКОГДА.** Мэт говорит только голосом
   `voice-00` + обработка «пиксель-голос»: обрезка тишины +
   rubberband (темп ×1.45, высота ×1.22) + биткраш acrusher 7 бит.
   Никаких прослушиваний-«вариантов» голосов пользователю не предлагать.
   Сырьё TTS без обработки — это ещё не голос Мэта; узнаваемый голос
   появляется только после пиксельной цепочки. Эталон: `mat-bot/voice/`.
2. **Без призывов «заходите в чат».** Никаких CTA про чат Acid Crunch
   в новых роликах: ни голосом, ни текстом на экране.
