# Клон @DeepStickBot — видеостикеры из фото

Бот делает то же, что и оригинал с точки зрения пользователя:
**прислал фото → выбрал стиль → выбрал/описал сценарий → получил готовый
видеостикер и ссылку на личный стикерпак.**

![пример результата](examples/sticker.gif)

---

## 1. Разбор: как это делает оригинал

Код @DeepStickBot закрыт, поэтому это реконструкция по его публичному описанию
и по требованиям Telegram. Его собственная реклама
([пост в @deepfaker](https://t.me/deepfaker/32)) говорит дословно:

> «Загрузи фото в DeepSticker, выбери стиль и опиши свой сценарий. Бот
> превратит твою идею в персональный видеостикер» + «фото-стикеры с готовыми
> реакциями можно попробовать бесплатно».

Отсюда пайплайн оригинала почти наверняка такой:

| Шаг | Что видит пользователь | Что происходит под капотом |
|---|---|---|
| 1 | Присылает фото | Бот скачивает файл (`getFile`), вероятно вырезает человека с фона и/или готовит референс для модели |
| 2 | Выбирает стиль | Стиль подмешивается в промпт генерации («мультяшный», «киберпанк»…) |
| 3 | Описывает сценарий текстом или жмёт готовую реакцию | Текст = промпт; готовые реакции = заранее написанные промпты/шаблоны |
| 4 | Ждёт ~минуту | **Image-to-video нейросеть** (класс Kling / Runway / Hailuo / Wan) анимирует фото по промпту, сохраняя внешность |
| 5 | Получает стикер + пак | Сгенерированное видео обрезается до ≤3 с, ресайзится в 512 px, кодируется в **WebM/VP9 ≤256 КБ** и кладётся в персональный стикерпак через Bot API (`createNewStickerSet` / `addStickerToSet`) |

Почему шаг 5 именно такой — это не фантазия, а жёсткие требования Telegram
к видеостикерам ([core.telegram.org/stickers](https://core.telegram.org/stickers),
[webm-vp9-encoding](https://core.telegram.org/stickers/webm-vp9-encoding)):

- контейнер **WebM**, кодек **VP9**, без аудиодорожки;
- одна сторона **ровно 512 px**, вторая ≤512 px;
- длительность **≤3 с**, **≤30 FPS**, размер **≤256 КБ**, зацикленность.

«Готовые реакции бесплатно» у оригинала, скорее всего, дешевле свободного
сценария именно потому, что это шаблоны: промпт (или даже движение) уже задан,
а кастомный сценарий — полноценная платная генерация. Поэтому нейро-генерация —
главная статья расходов такого бота, а не стикеры сами по себе.

## 2. Что сделано здесь

Тот же флоу, но с двумя режимами генерации:

| | 🆓 Локальный (по умолчанию) | 🧠 Нейро (`AI_PROVIDER=...`) |
|---|---|---|
| Как анимирует | Вырезает фон (`rembg/u2net`), добавляет белую обводку и анимирует объект Pillow-эффектами: 🚀 ракета, 💃 танец, 😂 тряска, 😍 сердечки, 🔥 искры, 🌀 портал, кружение, прыжки и т.д. | Фото + промпт уходят в image-to-video модель (Replicate/fal.ai, по умолчанию Kling), как у оригинала |
| Свой сценарий текстом | Подбирает ближайший эффект по ключевым словам | Уходит в модель **как есть** — «дирижирую оркестром котов» сработает буквально |
| Скорость | ~5–10 секунд | ~1–5 минут |
| Цена | 0 ₽, нужен только сервер | Платится провайдеру модели за каждую генерацию |
| Зависимости | ffmpeg (или встроенный из `imageio-ffmpeg`) | + API-ключ Replicate или fal.ai |

Дополнительно бот умеет то же, что «конвертерные» боты: **присланное видео/GIF
≤10 c превращается в видеостикер** (обрезка до 3 c, 512×512, VP9, влезание в 256 КБ).

Свободный сценарий в локальном режиме честно ограничен набором эффектов —
настоящая «магия по любому тексту» требует нейро-режима.

## 3. Запуск

### 3.1. Создай своего бота

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен.
2. Скопируй конфиг: `cp .env.example .env` и впиши `BOT_TOKEN`.

### 3.2. Вариант A — Docker (рекомендуется)

```bash
docker compose up -d --build
```

### 3.2. Вариант B — просто Python

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-rembg.txt   # с вырезанием фона
# или: pip install -r requirements.txt # лёгкий вариант без вырезания фона
python bot.py
```

ffmpeg не обязателен: если его нет в системе, возьмётся бинарь из пакета
`imageio-ffmpeg` (VP9 в нём есть — проверено).

### 3.3. Нейро-режим (необязательно)

В `.env` одно из двух:

```dotenv
AI_PROVIDER=replicate
REPLICATE_API_TOKEN=r8_...
# REPLICATE_MODEL=kwaivgi/kling-v1.6-standard

# или
AI_PROVIDER=fal
FAL_KEY=...
# FAL_MODEL=fal-ai/kling-video/v1.6/standard/image-to-video
```

Если нейросеть упадёт/кончится баланс — бот сам откатится на локальную
анимацию и предупредит пользователя, а не просто сломается.

## 4. Проверка без Telegram

```bash
python tools/make_demo.py                 # само сгенерирует тестовое фото
python tools/make_demo.py my.jpg --effect dance --style cartoon --gif
python -m pytest tests/                   # проверяет, что .webm проходит требования TG
```

Пример вывода проверки готового файла:

```
{'codec': 'vp9', 'width': 512, 'height': 512, 'fps': 30.0,
 'duration': 2.8, 'size': 238595, 'has_audio': False}   # лимит — 262144 байта
```

## 5. Структура

```
bot.py               — aiogram-бот: флоу фото→стиль→сценарий, FSM, хендлеры
config.py            — настройки из .env
app/scenarios.py     — 12 сценариев + 4 стиля + подбор эффекта по свободному тексту
app/effects.py       — стилизация, обводка, покадровая Pillow-анимация (бесшовный луп)
app/rembg_wrap.py    — вырезание фона (u2net), мягкий fallback без него
app/encode.py        — WebM/VP9 под лимиты TG: подбор битрейта до влезания в 256 КБ
app/ai_video.py      — Replicate / fal.ai image-to-video (поллинг очереди)
app/packs.py         — персональный пак ds_<user_id>_by_<bot> через Bot API
tools/make_demo.py   — офлайн-генерация .webm/.gif без Telegram
tests/               — тест соответствия файла требованиям Telegram
```

## 6. Честные ограничения

- **1-в-1 «как оригинал» = нейро-режим.** Локальные эффекты — это оживление
  вырезанного объекта, а не генерация нового видео: человек не «сядет на ракету»
  по-настоящему, он полетит на ней как стикер-объект (см. GIF выше). Для
  буквального повторения нужен ключ image-to-video модели.
- Качество сохранения лица в нейро-режиме зависит от модели (Kling/Wan и т.п.),
  а не от этого бота — бот лишь правильно формирует промпт и перепаковывает результат.
- Модель `u2net` (~170 МБ) скачивается при первом вырезании фона в `~/.u2net`.
- Не используй чужие фото без разрешения человека на них — особенно в нейро-режиме.
