# «СМОТРИТЕ, КАК Я УМЕЮ» — сценарий шоурила на 15 секунд

Аналог присланного ролика `VID_20261016_130422_134.mp4` (1080×1920, 15 с),
но от первого лица и с подписью **VADIM / MOTION**.
Всё — включая звук — делается одним файлом кода: `showreel/render.py`
(Pillow + NumPy, сборка ffmpeg). Без редактора, плагинов и готовых футажей.

| Время | Сцена | Что на экране |
|---|---|---|
| 0.0–1.8 | SC 01 | На бегущем коде: «СМОТРИТЕ, / КАК Я / УМЕЮ», ниже оранжевая плашка со счётчиком — честное число строк в самом `render.py` |
| 1.8–3.6 | SC 02 | Оранжевый фон, кинетическая типографика: «ДВИЖЕНИЕ» вертикально, контурные повторы по краям |
| 3.6–5.4 | SC 03 | 3D-куб чистой математикой проекции (без 3D-движка), грани: КОД → РИТМ → ЗВУК → КАДР, верх — «3D» |
| 5.4–7.2 | SC 04 | 2 600 частиц: вспышка → кольцо → собираются в «15 СЕКУНД» → разлетаются |
| 7.2–9.0 | SC 05 | Счётчик 000 → 450 КАДРОВ, живой эквалайзер, подписи 30 FPS / 1080×1920 / 15.0 S |
| 9.0–10.8 | SC 06 | Вращающиеся квадраты и окружности, стикеры: «БЕЗ ПЛАГИНОВ» → «БЕЗ ШАБЛОНОВ» → «ТОЛЬКО КОД» |
| 10.8–12.6 | SC 07 | Светлый фон: «SHOW / REEL», строка «КОД • РИТМ • ЧАСТИЦЫ • ЗВУК», в конце — инверсия и глитч |
| 12.6–15.0 | SC 08 | Финал на чёрном: **VADIM**, оранжевая черта, «MOTION • CODE • SOUND», «SHOWREEL • 2026», «СДЕЛАНО КОДОМ ЗА 15 СЕКУНД» |

Поверх всех сцен — «камера»: ● REC, таймкод TC, номер сцены SC xx/08,
прогресс-бар и подпись VADIM / MOTION, как в оригинале.

Звук синтезируется в том же файле: бит 120 BPM (кик, хэты, клэпы, бас),
удары на склейках сцен, подъём перед финалом и аккорд Am в финале.

## Как пересобрать

```bash
pip install Pillow numpy imageio-ffmpeg
python3 showreel/render.py            # полный рендер -> out9/
python3 showreel/render.py --preview  # быстрый черновик 360×640
```

Результат: `out9/клип.mp4` (+ обложка, раскадровка и отчёт).
Шрифты в `assets/fonts/` — Montserrat и JetBrains Mono (лицензия OFL 1.1).

Хотите другое имя в финале или другой текст — правка одной строки
`AUTHOR = "VADIM"` и надписей в сценах в `render.py`, затем перерендер.
