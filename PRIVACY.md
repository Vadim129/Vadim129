# Приватность «Книжного голоса»

## Gemini AI — только по явному выбору владельца

- Gemini является единственным движком озвучки приложения и начинает работу только после того, как пользователь сам добавит свой Gemini API key.
- Ключ создаётся владельцем в [Google AI Studio](https://aistudio.google.com/apikey). Общий, скрытый или разработческий ключ в APK отсутствует.
- Во время активной озвучки приложение отправляет в Gemini API только новый длинный фрагмент текста книги, выбранный голос и параметры синтеза. Уже созданные фрагменты сначала берутся из локального аудиокэша и повторно в API не отправляются.
- Готовое PCM-аудио сохраняется в закрытом no-backup-хранилище приложения, отдельно для каждой книги, голоса и точного текста. Кэш ограничен одной третью свободного места устройства и максимумом 768 МиБ; самые старые фрагменты удаляются автоматически. Удаление книги удаляет её кэш.
- Ключ хранится только локально: обычно — зашифрованным Android Keystore; если Keystore недоступен на прошивке, применяется отдельный AES-ключ в закрытом no-backup-хранилище приложения. Сам API-ключ не сохраняется в настройках открытым текстом.
- Ключ можно удалить отдельной кнопкой непосредственно в окне его ввода.
- Лимиты, доступность, бесплатная квота и обработка данных Gemini определяются условиями Google и аккаунтом пользователя.

## Остальные данные

- Импортированные файлы, список книг, позиция чтения, выбор голоса и кэш озвучки хранятся на устройстве.
- Приложение не содержит рекламу, трекеры, аналитику, Firebase или сервер разработчика.
