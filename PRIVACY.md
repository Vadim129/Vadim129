# Приватность «Книжного голоса»

## Встроенная озвучка Android

- Приложение использует только стандартный API Android Text-to-Speech и установленный владельцем речевой движок.
- В приложении нет облачного API озвучки, API-ключей, общего ключа или сервера разработчика.
- Приложение не запрашивает разрешение `INTERNET` и само не передаёт текст книги во внешний сервис.
- Движок Android TTS выбирается и настраивается владельцем в настройках телефона. Некоторые системные голоса работают локально, а некоторые могут требовать сеть; правила обработки данных в таком случае задаёт сам выбранный движок.

## Данные на устройстве

- Импортированные файлы, список книг, позиция чтения, выбранный голос и скорость хранятся только на устройстве.
- При озвучивании читалка временно передаёт текст лишь встроенному Android-речевому движку на том же устройстве.
- Приложение не содержит рекламу, трекеры, аналитику, Firebase или сервер разработчика.
