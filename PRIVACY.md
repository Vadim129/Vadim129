# Приватность «Книжного голоса»

## Офлайн Piper

- В APK включены два русских нейросетевых Piper/VITS голоса: Ирина и Дмитрий.
- Они работают целиком на устройстве: текст книги, аудио и позиция чтения не покидают телефон.
- Для Piper не нужен аккаунт, ключ, интернет или платёж.

## Gemini AI — только по явному выбору владельца

- Gemini выключен по умолчанию. Пользователь сам выбирает его в меню «Движок» и вводит собственный Gemini API key на своём устройстве.
- Только при активной озвучке Gemini приложение отправляет в Google API текущий небольшой фрагмент текста книги, выбранное имя голоса и параметр языка `ru-RU`.
- Общий/скрытый ключ в APK отсутствует. Обычно ключ пользователя шифруется Android Keystore; на устройствах с неисправным или недоступным Keystore применяется отдельный AES-ключ из закрытого no-backup-хранилища приложения. Сам ключ не хранится в настройках открытым текстом, не покидает устройство и может быть удалён в настройках Gemini.
- Лимиты, доступность и обработка данных в Gemini определяются условиями Google и аккаунтом пользователя.

## Остальные данные

- Импортированные файлы копируются только во внутреннее хранилище приложения.
- Список книг, позиция чтения и настройки TTS хранятся локально.
- Приложение не содержит рекламу, трекеры или аналитику.
