# Клип «Фонтанчик с чёрным дельфином»

Сборка: `python3 clip/build.py` (нужны `pillow numpy imageio-ffmpeg`, для титров — `vosk`).

Синхронизация текста:
1. `python3 clip/asr.py` — распознаёт вокал с таймкодами (Vosk, модель
   `vosk-model-small-ru-0.22`, кладётся в `/tmp/voskru/`, в git не хранится).
2. `python3 clip/align.py` — выравнивает канонический текст (`clip/lyrics.txt`)
   на распознанные слова (DP по сходству слов) и пишет `clip/timing.json`
   с границами каждой строки и каждого слова.

В записи два прохода по 21 строке (≈23.7–96 с и ≈110.4–186.4 с), припев
и финальная строка повторяются — это видно в `timing.json`.

Кадры `03-yard`, `17-football`, `25-haircut`, `34-walk-yard` исключены:
прогулок/футбола во дворе «Чёрного дельфина» быть не может.


## Вторая редакция кадров (101–149)

50 новых кадров по смыслу: суд (101–107), автозак (108–110), этап/поезд (111–114),
дорога и ворота колонии (115–118, 141), приём (119–120), конвой и поверка (121–122,
149, 143), камера (123–129, 145, 142, 147), быт (130–136, 128, 144), фонтан (137–138,
148, 140). Порядок задан в `SEQUENCE` в `build.py`.

Убрано: 139 (два дельфина в кадре), 146 (абракадабра вместо текста на карточке),
старые кадры с прогулками и выходом из тюрьмы, заставка с именем и названием песни,
бэк-вокал в титрах.
