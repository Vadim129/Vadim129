# Книжный голос / BookVoice

Android-читалка с **двумя нейросетевыми путями озвучки русского текста**: бесплатным офлайн Piper и Gemini AI по ключу владельца.

## Что умеет

- импортировать `EPUB`, `FB2`, `PDF`, `TXT`, `HTML/HTM` и `DOCX` через системный выбор файла;
- держать библиотеку книг «читаю сейчас» и показывать прогресс по каждой книге;
- открывать книгу там, где пользователь остановился — позиция сохраняется при перелистывании, во время озвучки и при выходе;
- озвучивать книгу фрагментами, ставить на паузу и продолжать с сохранённого места;
- выбирать движок, голос и скорость прямо в читалке.

## Нейроголоса

### Piper — сразу в APK, полностью офлайн и бесплатно

В сборку включены два русских VITS/Piper medium int8 голоса:

- **Piper Ирина**;
- **Piper Дмитрий**.

Это именно **Sherpa-ONNX + VITS внутри APK**, а не системный Android TTS: голоса работают локально на устройстве, без аккаунта, сети, лимита символов или передачи текста. Аудио выдаётся по предложениям, пока движок уже готовит следующие, а количество CPU-потоков подбирается для телефона (до 4), чтобы убрать долгую паузу перед началом чтения. Это основной режим приложения при первом запуске.

### Gemini AI — выразительная облачная озвучка

В «Движок» → **Gemini AI** пользователь добавляет **свой** Gemini API key, созданный в Google AI Studio, и выбирает один из встроенных голосов. Приложение использует `gemini-3.8-flash-tts` с языком `ru-RU` и передаёт Google только тот фрагмент книги, который нужно озвучить сейчас.

API-ключ не вшивается в APK и не отправляется разработчику. В нормальном случае он шифруется Android Keystore на самом телефоне. Если конкретная прошивка не даёт создать Keystore-ключ, приложение автоматически использует отдельный AES-ключ в закрытом no-backup-хранилище приложения — сам API-ключ всё равно не хранится в настройках открытым текстом и остаётся только на устройстве. У Google может быть доступна бесплатная квота, но её наличие, регион и лимиты определяет Google — приложение не обещает и не обходит платные лимиты. Без ключа используйте Piper: он бесплатен без условий.

Системные Android TTS-движки сохранены как запасной вариант, но не являются режимом по умолчанию.

> Для PDF извлекается встроенный текст локально на устройстве. Сканированные PDF без текстового слоя требуют OCR до импорта.

## Сборка APK

Крупные, проверяемые по SHA-256 модели и нативный runtime не хранятся в Git. Перед локальной сборкой один раз загрузите их:

```bash
bash scripts/fetch-neural-tts-assets.sh
./gradlew :app:assembleDebug
```

Готовый устанавливаемый APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions автоматически получает закреплённые модели, проверяет их SHA-256, собирает APK и публикует артефакт **bookvoice-apk**.

## Приватность

- Piper и разбор книг работают локально.
- При включённом Gemini по сети уходят только озвучиваемые фрагменты текста и только на Gemini API; это действие явно выбирает владелец приложения.
- Список книг, позиция чтения, Piper-модели и выбранный TTS-голос остаются на устройстве.
- Gemini API key шифруется Android Keystore, а на несовместимых прошивках — отдельным AES-ключом из закрытого no-backup-хранилища приложения; ключ можно удалить из окна настройки Gemini.
