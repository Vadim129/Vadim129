# Книжный голос / BookVoice

Android-читалка с озвучкой русского текста через **Gemini AI TTS**. Приложение не содержит встроенного общего API-ключа: каждый владелец добавляет свой ключ Google AI Studio.

## Что умеет

- импортировать `EPUB`, `FB2`, `PDF`, `TXT`, `HTML/HTM` и `DOCX` через системный выбор файла;
- вести библиотеку «читаю сейчас» и сохранять прогресс;
- открывать книгу с последней позиции;
- озвучивать её голосами Gemini AI, останавливать и продолжать с сохранённого места;
- выбирать голос Gemini и скорость прямо в читалке.

## Gemini AI TTS

1. В читалке нажмите **«Ключ»**.
2. Откройте ссылку **[aistudio.google.com/apikey](https://aistudio.google.com/apikey)** и создайте личный Gemini API key.
3. Вставьте ключ, сохраните его и выберите голос кнопкой **«Голос»**.

Приложение использует `gemini-3.8-flash-lite-tts` — быстрый вариант Gemini 3.8 TTS для чтения вслух. Чтобы между фрагментами не было заметных пауз, приложение держит очередь из трёх ближайших фраз: следующие запросы генерируются параллельно, пока звучит текущая фраза, а звук идёт через один непрерывный AudioTrack.

Ключ не вшивается в APK и не отправляется разработчику. Сначала он шифруется Android Keystore. Если Keystore на конкретной прошивке не работает, используется отдельный AES-ключ в закрытом no-backup-хранилище приложения; сам API-ключ не хранится в настройках открытым текстом. В окне **«Ключ»** есть отдельная кнопка удаления ключа с устройства.

Gemini является облачным сервисом: при озвучивании в Google отправляются только ближайшие читаемые фрагменты книги, выбранный голос и параметры генерации. Доступность бесплатной квоты, лимиты и условия определяет Google и аккаунт владельца.

> Для PDF извлекается встроенный текст локально на устройстве. Сканированные PDF без текстового слоя требуют OCR до импорта.

## Сборка APK

```bash
./gradlew :app:assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions собирает APK и публикует артефакт **bookvoice-apk**.

## Приватность

- Импортированные книги, библиотека и позиция чтения хранятся на устройстве.
- При нажатии «Озвучить» в Gemini API передаются только фрагменты, необходимые для текущей очереди чтения.
- В приложении нет рекламы, аналитики, Firebase, скрытого ключа или сервера разработчика.
