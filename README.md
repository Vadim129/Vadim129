# Ритм-виджет / Rhythm Overlay

Нативное Android-приложение с перетаскиваемым прямоугольным эквалайзером поверх любых приложений.

## Что умеет

- Показывает компактный **плавающий виджет** поверх экрана после явного разрешения пользователя.
- Перетаскивается за верхнюю панель и закрывается крестиком в правом верхнем углу.
- Имеет 13 оригинальных Canvas-скинов: неон, северное сияние, закат, стекло, пиксельный клуб, Matrix, космос, две танцующие DJ и пять танцующих животных (кошка, лис, панда, капибара).
- Позволяет менять скин, размер, прозрачность, чувствительность и источник анимации прямо в приложении.
- На Android 10+ предлагает **явный системный захват воспроизводимого звука**. Android разрешает захватывать только приложения, которые сами не отключили playback capture. Есть также best-effort системная аудиосессия и вариант с микрофоном для музыки из динамиков.
- Не сохраняет и не отправляет звук: в памяти остаются только текущие 16 уровней спектра.

## Как запустить на телефоне

1. Установите `RhythmOverlay-v1.0.1.apk`.
2. Откройте **Ритм-виджет** и нажмите «Включить плавающий виджет».
3. В системном экране разрешите показ поверх других приложений.
4. Для реакции на звук нажмите «Подключить звук телефона» и подтвердите системный запрос Android. Если источник не разрешает захват, выберите режим микрофона или демо в настройках.

> APK подписан debug-ключом для прямой установки. Если Android сообщает, что конфликтует подпись приложения с таким же package name, удалите более старую сборку `com.vadim129.rhythmoverlay` и установите APK снова.

## Сборка без Android Studio

В репозитории нет Gradle-зависимостей. Скрипт сам загружает временный JDK 17, Android API stubs, `aapt2`, D8 и APK signer только из GitHub/npm, затем выпускает APK:

```bash
chmod +x scripts/build-apk.sh
./scripts/build-apk.sh
```

Готовый файл будет в `release/RhythmOverlay-v1.0.1.apk`; каталог `release/`, `.tools/` и `.apk-build/` намеренно не отслеживаются Git.
