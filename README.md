# Ритм-виджет / Rhythm Overlay

Нативное Android-приложение с прозрачным, перетаскиваемым музыкальным эквалайзером поверх любых приложений.

## Что умеет

- Показывает прозрачный плавающий виджет: **без плашки-фона, рамки с подложкой и надписей** поверх экрана — видны только выбранная графика и полосы эквалайзера.
- Один палец перемещает виджет; жест «щипок» (раздвинуть / сдвинуть два пальца) изменяет его размер. Долгое нажатие открывает настройки.
- Содержит **100 самостоятельных Canvas-скинов**: все масти карт, рубины, сапфиры, изумруды, аметисты, огонь, вода, лёд, молнии, солнечные и лунные композиции, созвездия, кометы, винил, кассеты, синтвейв, аркада, сакура, лотос, пузыри, чернила и голограммы. Это 25 разных графических движков по четыре отдельные композиции, а не одна картинка в других цветах.
- Позволяет менять скин, размер, прозрачность, чувствительность и источник анимации прямо в приложении.
- На Android 10+ предлагает **явный системный захват воспроизводимого звука**. Android разрешает захватывать только приложения, которые сами не отключили playback capture. Есть также best-effort системная аудиосессия и вариант с микрофоном для музыки из динамиков.
- Не сохраняет и не отправляет звук: в памяти остаются только текущие 16 уровней спектра.

## Как запустить на телефоне

1. Установите `RhythmOverlay-v1.1.0.apk`.
2. Откройте **Ритм-виджет** и нажмите «Включить плавающий виджет».
3. В системном экране разрешите показ поверх других приложений.
4. Тяните визуализатор одним пальцем; удерживайте его для настроек; двумя пальцами меняйте размер.
5. Для реакции на звук нажмите «Подключить звук телефона» и подтвердите системный запрос Android. Если источник не разрешает захват, выберите режим микрофона или демо в настройках.

> APK подписан debug-ключом для прямой установки. Если Android сообщает, что конфликтует подпись приложения с таким же package name, удалите более старую сборку `com.vadim129.rhythmoverlay` и установите APK снова.

## Сборка и контроль качества

GitHub Actions собирает APK на JDK 17/Android API 35. Перед публикацией запускается `scripts/qa-checks.sh`: в нём десять проверок APK, манифеста, подписи debug-сборки, каталога из 100 скинов, прозрачного рендера и реализаций жестов.

Для локальной сборки без Android Studio доступен также скрипт:

```bash
chmod +x scripts/build-apk.sh
./scripts/build-apk.sh
```

`qa-checks.sh` использует `aapt` и `apksigner` из полноценного Android SDK, поэтому все десять проверок гарантированно запускаются в CI. Готовый пакет публикуется в `release/RhythmOverlay-v1.1.0.apk`; временные `.tools/` и `.apk-build/` намеренно игнорируются Git.
