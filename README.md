# Ритм-виджет / Rhythm Overlay

Нативное Android-приложение с прозрачным, перетаскиваемым аудиовизуализатором поверх любых приложений.

## Что умеет

- Показывает прозрачный плавающий виджет: **без фоновой плашки, рамки и текстовых надписей** поверх экрана — видна только реагирующая на звук визуализация.
- Один палец перемещает виджет; жест «щипок» (раздвинуть / сдвинуть два пальца) изменяет его размер.
- Долгое удержание показывает два явных управляющих символа прямо на виджете: **шестерёнку** для настроек и **крестик** для закрытия. Это не закрывает виджет случайным обычным касанием.
- Содержит **100 самостоятельных аудиовизуализаторов**: 10 узнаваемых форм по 10 пресетов — линейный и зеркальный спектр, LED-сегменты, точечный спектр, осциллограф, круговой спектр, орбиты, аудиотуннель, частицы и танцевальные сцены. Пресеты отличаются геометрией, якорем, сегментацией и движением, а не только цветом.
- В танцевальных сценах используются 60 прозрачных PNG-кадров, подготовленных из подходящих GIF пользователя. Кадр, прыжок и масштаб выбираются из энергии баса, поэтому это не просто бесконечно проигрываемая GIF-анимация.
- Позволяет менять визуализатор, размер, прозрачность, чувствительность и источник анимации прямо в приложении.
- На Android 10+ предлагает **явный системный захват воспроизводимого звука**. Android разрешает захватывать только приложения, которые сами не отключили playback capture. Есть также best-effort системная аудиосессия и вариант с микрофоном для музыки из динамиков.
- Не сохраняет и не отправляет звук: в памяти остаются только текущие 16 уровней спектра.

## Как запустить на телефоне

1. Установите `RhythmOverlay-v1.2.0.apk`.
2. Откройте **Ритм-виджет** и нажмите «Включить плавающий виджет».
3. В системном экране разрешите показ поверх других приложений.
4. Тяните визуализатор одним пальцем; раздвигайте или сдвигайте двумя пальцами, чтобы изменить размер.
5. Чтобы открыть настройки либо закрыть его с самого overlay, удерживайте виджет и нажмите появившуюся шестерёнку либо крестик.
6. Для реакции на звук нажмите «Подключить звук телефона» и подтвердите системный запрос Android. Если источник не разрешает захват, выберите режим микрофона или демо в настройках.

> Начиная с v1.2.0 APK подписывается постоянным ключом `app/signing/rhythm-overlay.keystore`, а package name остаётся `com.vadim129.rhythmoverlay`: следующие сборки этой линии ставятся поверх предыдущей. v1.1.0 был подписан одноразовым runner debug-ключом, поэтому Android может один раз потребовать удалить именно v1.1.0 перед установкой v1.2.0; после перехода удалять приложение для обновлений не потребуется.

## Сборка и контроль качества

GitHub Actions собирает APK на JDK 17/Android API 35. При первом запуске workflow создаёт и сохраняет постоянную подпись, затем использует её для каждой следующей сборки. Перед публикацией запускается `scripts/qa-checks.sh`: в нём десять проверок APK, манифеста и версии, постоянной подписи, SHA-256, каталога из 100 нормальных визуализаторов, прозрачного audio-reactive рендера с beat-synced танцем и жестов drag/pinch/hold/close.

Для локальной сборки без Android Studio доступен также скрипт:

```bash
chmod +x scripts/build-apk.sh
./scripts/build-apk.sh
```

Локальная сборка намеренно требует уже созданный `app/signing/rhythm-overlay.keystore`, чтобы случайно не выпустить APK с другой подписью. `qa-checks.sh` использует `aapt`, `apksigner` и `keytool` из полноценного Android SDK/JDK, поэтому все десять проверок гарантированно запускаются в CI. Готовый пакет публикуется в `release/RhythmOverlay-v1.2.0.apk`; временные `.tools/` и `.apk-build/` намеренно игнорируются Git.
