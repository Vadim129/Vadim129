# Vadim129

## Скилл: видео кодом по примеру или сценарию

`skills/video-by-code/` — агентный скилл: по загруженному видео-примеру
(или текстовому сценарию) делает аналогичный короткий ролик полностью
кодом — разбор примера, JSON-сценарий, покадровый рендер и звук на
Python, проверка результата. Указатели для агентов: `.claude/skills/`,
`.agents/skills/`. Подробно: `skills/video-by-code/README.md`.

Пример результата: `out9/клип.mp4`, код — `showreel/render.py`
и обобщённый `skills/video-by-code/scripts/render.py`.
