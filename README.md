# Книжный голос / BookVoice

Android-читалка для русского текста со **встроенной озвучкой Android TTS**. В приложении нет облачной озвучки, API-ключей и общего сервера: оно использует речевой движок и голос, установленные на телефоне.

## Что умеет

- импортировать `EPUB`, `FB2`, `PDF`, `TXT`, `HTML/HTM` и `DOCX` через системный выбор файла;
- вести библиотеку «читаю сейчас», открывать книгу с последней позиции и автоматически сохранять прогресс;
- озвучивать текст встроенным Android TTS, останавливать и продолжать с сохранённого места;
- выбирать доступный русский системный голос и скорость прямо в читалке;
- подсвечивать читаемое слово или диапазон текста во время озвучивания.

## Встроенная озвучка Android

1. Откройте книгу и нажмите **«Озвучить»**.
2. Нажмите **«Голос»**, чтобы выбрать русский голос, установленный на устройстве.
3. Нажмите на значение скорости (например, `1×`), чтобы изменить темп речи.

Если русских голосов нет, кнопка «Голос» предложит открыть настройки Android TTS. Установите русский голос в системных настройках и вернитесь в приложение — оно заново подключится к речевому движку.

Когда движок Android сообщает диапазоны слов, приложение подсвечивает точное слово или фразу. Некоторые устройства сообщают только начало и конец фрагмента; для них читалка показывает плавно перемещающуюся подсветку по текущему фрагменту, чтобы текст всё равно был виден во время речи.

> Для PDF извлекается встроенный текст локально на устройстве. Сканированные PDF без текстового слоя требуют OCR до импорта.

## Сборка APK

```bash
./gradlew :app:assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions собирает APK и публикует артефакт **bookvoice-apk**.

## Приватность

- Импортированные книги, библиотека, позиция чтения, выбор голоса и скорость хранятся на устройстве.
- Приложение не имеет разрешения `INTERNET`, не передаёт текст книг внешнему API и не требует ключей.
- Сам Android-речевой движок может быть настроен владельцем как локальный или сетевой; его политика обработки данных определяется выбранным движком и настройками телефона.
- В приложении нет рекламы, аналитики, Firebase, скрытого ключа или сервера разработчика.
