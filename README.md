# Книжный голос / BookVoice

Android-читалка с бесплатной озвучкой на базе установленных на устройстве TTS-движков.

## Что умеет

- импортировать `EPUB`, `FB2`, `PDF`, `TXT`, `HTML/HTM` и `DOCX` через системный выбор файла;
- держать библиотеку книг «читаю сейчас» и показывать прогресс по каждой книге;
- открывать книгу там, где пользователь остановился — позиция сохраняется при перелистывании, во время озвучки и при выходе;
- озвучивать текст через **все доступные системные TTS-движки и голоса**, выбирать голос, скорость и движок прямо в читалке;
- работать без регистрации, аккаунта, рекламы и облачного API. Текст книги и настройка голоса остаются на устройстве.

TTS использует Android `TextToSpeech`: это бесплатный и самый совместимый способ получить качественные офлайн- и нейроголоса, уже установленные на телефоне. Для новых голосов откройте системные настройки Android → «Синтез речи» и скачайте доступные голосовые пакеты; приложение автоматически покажет их в списке.

> Для PDF извлекается встроенный текст локально на устройстве. Сканированные PDF без текстового слоя требуют OCR до импорта.

## Сборка APK

```bash
./gradlew :app:assembleDebug
```

Готовый устанавливаемый APK: `app/build/outputs/apk/debug/app-debug.apk`.

CI GitHub Actions собирает этот APK и публикует его как артефакт **bookvoice-apk**.

## Приватность

Приложение не запрашивает разрешение на интернет или доступ ко всему накопителю. Книга выбирается через Android Storage Access Framework, затем сохраняется в приватной папке приложения, чтобы прогресс чтения не зависел от внешнего файлового менеджера.
