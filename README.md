# Книжный голос / BookVoice

Android-читалка с озвучкой русского текста через **Gemini AI TTS**. Приложение не содержит встроенного общего API-ключа: каждый владелец добавляет свой ключ Google AI Studio.

## Что умеет

- импортировать `EPUB`, `FB2`, `PDF`, `TXT`, `HTML/HTM` и `DOCX` через системный выбор файла;
- вести библиотеку «читаю сейчас» и сохранять прогресс;
- открывать книгу с последней позиции;
- озвучивать её голосами Gemini AI, останавливать и продолжать с сохранённого места;
- сохранять уже созданное аудио локально и при повторном прослушивании не расходовать Gemini API-запросы;
- выбирать голос Gemini и скорость прямо в читалке.

## Gemini AI TTS и экономия квоты

1. В читалке нажмите **«Ключ»**.
2. Откройте ссылку **[aistudio.google.com/apikey](https://aistudio.google.com/apikey)** и создайте личный Gemini API key.
3. Вставьте ключ, сохраните его и выберите голос кнопкой **«Голос»**.

Приложение использует `gemini-3.8-flash-lite-tts` — быстрый и экономичный вариант Gemini 3.8 TTS для потокового чтения. Вместо трёх коротких запросов при старте оно запрашивает один длинный безопасный фрагмент (до примерно 5 000 символов), а следующий начинает готовить, пока звучит текущий. Это резко уменьшает количество API-запросов в день и не тратит несколько запросов сразу до начала прослушивания.

Каждый завершённый фрагмент сохраняется как локальный PCM-аудиокэш, привязанный к конкретной книге, тексту, голосу и формату аудио. При повторном запуске, возврате к уже озвученному месту или продолжении после остановки он воспроизводится с устройства без нового обращения к Gemini. Кэш — закрытые файлы приложения без резервного копирования; он использует не более одной трети свободного места и не более 768 МиБ, автоматически удаляя самые старые фрагменты. Удаление книги удаляет и её аудиокэш.

Ключ не вшивается в APK и не отправляется разработчику. Сначала он шифруется Android Keystore. Если Keystore на конкретной прошивке не работает, используется отдельный AES-ключ в закрытом no-backup-хранилище приложения; сам API-ключ не хранится в настройках открытым текстом. В окне **«Ключ»** есть отдельная кнопка удаления ключа с устройства.

Gemini является облачным сервисом: для нового фрагмента в Google отправляются его текст, выбранный голос и параметры генерации. Доступность бесплатной квоты, лимиты и условия определяет Google и аккаунт владельца. Кэш снижает число повторных запросов, но не может увеличить установленную Google суточную квоту на новое аудио.

> Для PDF извлекается встроенный текст локально на устройстве. Сканированные PDF без текстового слоя требуют OCR до импорта.

## Сборка APK

```bash
./gradlew :app:assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions собирает APK и публикует артефакт **bookvoice-apk**.

## Приватность

- Импортированные книги, библиотека, позиция чтения и сохранённый аудиокэш хранятся только на устройстве.
- При нажатии «Озвучить» в Gemini API передаётся только текст нового длинного фрагмента, который ещё не найден в локальном кэше, а также выбранный голос и параметры генерации.
- В приложении нет рекламы, аналитики, Firebase, скрытого ключа или сервера разработчика.
