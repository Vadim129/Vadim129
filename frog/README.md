# DJ FROG — «Marsh Groove»

2-минутный вертикальный клубный клип: лягушка в соломенной шляпе танцует под
собственный трек 128 BPM. Всё собрано локально из одного портрета 640×640 —
без внешних видео-сервисов.

## Результат

| файл | что это |
| --- | --- |
| `media/dj_frog.mp4` | 1080×1920, 30 fps, 120.000 с (3600 кадров), H.264 High + AAC 192 kbps, 86 МБ |
| `media/track.wav` | музыка, 44.1 кГц, стерео, 16 бит, ровно 120.000 с |
| `media/poster.jpg` | постер кадра из дропа |

## Как это сделано

1. **`prep.py`** — из `assets/frog.jpg` собирает все ассеты:
   * `frog.png` — RGBA-вырез: маттинг по светлоте/насыщенности, зачистка
     белых студийных полос внутри силуэта (медианный фильтр), эрозия мата
     на 2 px и де-фринж (внешняя область заливается цветом изнутри).
   * `iris{L,R}.png`, `sclera{L,R}.png`, `eyes.json` — глазное яблоко
     комопозитится заново каждый кадр: белок с вырезанной радужкой + радужка,
     которую можно двигать (взгляд) и моргать.
   * `lidstack{L,R}.npz` — 26 уровней «века»: кожа со лба стягивается вниз по
     глазу и сжимается; так моргание выглядит как настоящая кожа, а не
     нарисованный круг.
   * `masks.npz` — веса частей для mesh-warp рига: шляпа, голова, торс,
     левая/правая рука, челюсть.
   * `sky.png` — процедурный клубный фон 1080×1920.
2. **`music.py`** — синтезирует трек: 128 BPM, F# minor, i–VI–III–VII
   (F#m–D–A–E), 64 такта = 120.000 с. Секции: интро 0–8, билд 8–12,
   грув 12–24, брейк 24–32, дроп 32–56, аутро 56–64 (такты).
   Кик/саб/клэп/хэты/стабы/арп, сайдчейн, лимитер.
3. **`render.py`** — рендер 1080×1920/30 fps:
   * mesh-warp риг: прыжок на бочке, качание корпуса по 2 такта, бэнг головой,
     пружина шляпы, «поющие» движения челюсти, памп плеч;
   * клуб: лазерные веера (за и перед персонажем), боке, конфетти, строб,
     эквалайзер на диджейском пульте, колонки, толпа;
   * камера: панч на кик, тряска на дропе, медленный дрейф зума;
   * грейд: сплит-тонирование, блум, виньетка; титры и энд-карточка.

## Запуск

```bash
cd /home/user/Vadim129
export PYTHONPATH=/home/user/.pylibs
python3 frog/prep.py                       # ассеты (≈2 с)
python3 frog/music.py                      # музыка (≈45 с)
python3 frog/render.py --preview 12,62,118 # стоп-кадры
python3 frog/render.py --out frog/media/silent.mp4          # ≈17 мин
ffmpeg -i frog/media/silent.mp4 -i frog/media/track.wav \
       -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart \
       frog/media/dj_frog.mp4
```

## Тайминг

| время, с | что происходит |
| --- | --- |
| 0–15 | интро: титры, лягушка «входит» в кадр, свет пробивается |
| 15–45 | грув: качание, памп плеч, первые лазеры |
| 45–52.5 | «HANDS UP» — руки вверх, билд |
| 60 / 63.75 / 67.5 | вспышки «DROP» + конфетти + строб |
| 45–105 | дроп: максимум движения, панч-ины, бэнг головой |
| 112–120 | энд-карточка и фейд |
