# «оно живое» — странный музыкальный ролик на 60 секунд

Готовый файл: **`оно-живое_клип_60s.mp4`** (960×960, 24 fps, 60.0 c, H.264 + AAC, ~45 МБ)
— лежит в Google Drive в той же папке, откуда взято исходное видео.

## Из чего собрано

| Слой | Что именно |
| --- | --- |
| Видео | `VID_20261031_004245_984.mp4` (Дола, 960×960, 10 с) — гоняется циклами с разной скоростью (0.7–2.4×) |
| Музыка | `clips/audio-beautiful-far-distance.mp3`, фрагмент 95–155 c, фейды 0.35/0.7 c |
| Графика | калейдоскоп, RGB-сплит, блочный глитч, edge-детект, ASCII-скан, круги/прицелы, HUD с таймкодом, бумажный «карандашный» кадр, инверсии и строб по битам |

Ритм привязан к 90 BPM: сетка 2.667 c на такт, первый сильный такт — 1.267 c.
Энергия кадра берётся из огибающей акустики (24 значения в секунду, `env.npy`),
поэтому глитч, тряска и вспышки на склейках попадают в музыку.

## Как пересобрать

Нужны `ffmpeg` (можно взять из `pip install imageio-ffmpeg`), `numpy`, `pillow`.
Все команды — из корня репозитория.

```bash
# 1. исходник -> 24 fps rgb-кадры (кэш ~0.7 ГБ в work/)
python3 clips/weird-60s/build_src.py
# 2. музыка (фрагмент + огибающая)
#    см. блок «music» в истории: ffmpeg -ss 95 -t 60 ... work/music.wav + work/env.npy
# 3. кадры -> mp4 и мукс со звуком
python3 clips/weird-60s/render.py work/video.mp4
ffmpeg -i work/video.mp4 -i work/music.wav -map 0:v -map 1:a -c:v libx264 -crf 25 -c:a aac work/ono-zhivoe_clip_60s.mp4
```

Скрипт `render.py` умеет рендерить отдельные кадры для проверки:
`python3 clips/weird-60s/render.py x.jpg 40,420,900` → `work/frames/f0040.jpg` и т. д.

Превью-контактный лист: `clips/weird-60s/preview.jpg`.
