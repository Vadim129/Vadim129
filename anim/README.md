# Ожившая картина — «Тихий ход»

Превращение одной статичной иллюстрации (робот за шахматной партией в
заброшенном храме) в 33-секундный атмосферный ролик 1080×1620, 30 fps, со
звуком. Всё построено на Python (NumPy / OpenCV / Pillow) и FFmpeg —
без внешних AI-сервисов и без GPU.

**Готовые файлы:**

| Файл | Формат | Где использовать |
|---|---|---|
| [`anim/media/living_painting_9x16.mp4`](media/living_painting_9x16.mp4) | 1080×1920 (9:16) | Reels, Shorts, TikTok, Stories |
| [`anim/media/living_painting.mp4`](media/living_painting.mp4) | 1080×1620 (2:3) | исходный формат картины |
| [`anim/media/score.wav`](media/score.wav) | 44.1 кГц стерео | отдельная партитура |

Обе версии — 33 с, 30 fps, H.264 + AAC. Кадр задаётся флагами
`--width/--height`: высота определяет масштаб, ширина только обрезает бока.

---

## Почему не anymotion / manim / AnimatedDrawings

| Инструмент | Что это | Почему не подошёл |
|---|---|---|
| [facebookresearch/ai4animationpy](https://github.com/facebookresearch/ai4animationpy) | нейросеть для генерации движения **3D-скелета** персонажа по mocap-данным | работает с 3D-ригом, а не с одной 2D-картинкой; нечего анимировать |
| [anymotion-agent/anymotion](https://github.com/anymotion-agent/anymotion) | AI-агент для **motion graphics** (HTML/CSS/JS → headless-браузер → MP4) | ему нужен API-ключ LLM и Node+Puppeteer; это про SaaS-объяснялки, а не про живопись |
| `manim` | математическая анимация (векторные сцены) | не ставится в этом окружении: нужны системные Pango/Cairo; и он про графики, а не про фото |
| AnimatedDrawings | риг **детских рисунков** (человечек с руками/ногами) | рассчитан на рисунок с конечностями на белом фоне; наш робот — живописный полутон |

Поэтому здесь собственный **2.5D-композитор**: изображение не «перерисовывается»
нейросетью, а разбирается на слои (глубина, объекты, свет, пыль), и каждый слой
двигается по своим законам. Это даёт честное ощущение объёма и жизни, полностью
детерминировано и воспроизводимо.

## Что происходит в кадре

| Время | Действие |
|---|---|
| 0.0–1.4 с | проявление из темноты, камера медленно наезжает |
| 1.4–2.8 с | лучи от окна «включаются», пыль поднимается |
| **2.6 с** | **робот просыпается: голова приподнимается, глаза загораются** |
| 4.2–8.2 с | поворачивается к доске и **склоняет голову набок, задумавшись** |
| 8.2–11 с | крупный план: наклон головы, лёгкое покачивание корпуса (дыхание) |
| **10.1–11.2 с** | **палец левой руки стучит по доске** |
| 12.2–14 с | выпрямляется, смотрит вниз на руку |
| 13.4–15.2 с | по фигуре под пальцем бежит золотое свечение |
| **15.2–18.2 с** | **ладья поднимается, описывает дугу и делает ход; правая рука подаётся вперёд** |
| 18.2 с | касание: удар, круговая волна, облачко пыли |
| **20.3 / 21.25 с** | **два одобрительных кивка головой** |
| 20–27 с | камера отъезжает, робот «выдыхает», рука опускается |
| 24–33 с | общий план, титр **«ТИХИЙ ХОД / the quiet move»**, затемнение |
| всё время | **слизь течёт вниз, капли набухают, срываются и падают** |

## Как это сделано

### 1. Анализ изображения → слои (`prep_assets.py`)

* **Поиск фигур** — цветовая маска по HSV (тёплые светлые тона), метки по
  distance transform, watershed, затем **GrabCut** в тесном боксе для аккуратной
  альфы. Из доски вырезана ладья, которая будет ходить (`rook.png`), а её место
  в фоне заделано построчной интерполяцией (`plate.png`).
* **Глаза** — яркие малонасыщенные блобы в области головы: центры найдены
  автоматически (879, 1082) и (962, 1061).
* **Кристаллы** — рукописные полигоны-осколки (цветовые пороги не берут
  обесцвеченные грани) + подсветка по зелёному контуру.
* **Глубина** — прокси-карта: колонны 0.3 → робот 0.58 → доска 0.76 →
  передний план 1.0, с размытием.
* **Свет** — маска окна и объёмные клинья-шахты, уходящие на стол.

### 2. Композитор (`render.py`)

* **2.5D-камера**: zoom/pan по ключевым кадрам (сглаживание smootherstep),
  микро-дрожание «с рук», дыхание фокуса.
* **Параллакс по глубине**: каждый пиксель сдвигается на `(0.5 − depth) × drift`
  — дальний план гуляет сильнее ближнего.
* **Свет**: мерцающие шахты, пульсация кристаллов на двух расстроенных частотах.
* **Частицы**: 170 пылинок со своей глубиной, мерцанием и скоростью.
* **Ладья**: спрайт с альфой, тень-контакт на доске, «speed glow» на дуге,
  ударная волна и облачко пыли при касании.
* **Пост**: S-кривая, тёплые света / холодные тени, bloom, виньетка,
  туман, зерно, вспышка при «включении» глаз, титр на мягком скриме.

### 2.1 Риг персонажа (mesh-warp)

Картинка — один слой, поэтому робот анимируется **деформацией изображения**,
а не перерисовкой:

* семь весовых карт с мягкими краями — голова, корпус, плечо и предплечье
  каждой руки, обе кисти;
* для каждого кадра считается поле смещений: каждая часть поворачивается вокруг
  своего пивота, веса смешиваются, границы растягиваются — швов не видно;
* угол держится маленьким (≤ 6°), потому что жёсткий поворот одного битмапа
  рвёт живопись; «взгляд в сторону» делается переносом + лёгким сжатием по X;
* глаза, блик под пальцем и тень ладьи берут координаты **через ту же
  трансформацию** — поэтому свет и взгляд всегда на месте.

### 2.2 Слизь

* маска жёлто-зелёной слизи из самой картины + процедурные капли (голова, шейка,
  хвост) на груди, плече и предплечье;
* медленно меняющееся поле течения сдвигает пиксели вниз (гравитация) —
  слизь «ползёт»;
* объём: тёмный контур по краю капли + бегущий блик, плюс отдельные капли,
  которые срываются, падают и лопаются искрой.

### 3. Звук (`audio.py`)

Полностью синтезирован на NumPy: низкий органный дрон, ветер (фильтрованный
шум), стеклянные чимы, свист и глухой стук при ходе, финальный аккорд-свелл,
свёртка со синтетическим ревером. Поверх — тихие сервоприводы на поворотах
головы и рук и «чавкающие» блипы слизи. 44.1 кГц, стерео, синхронизировано с
событиями ролика.

## Запуск

```bash
pip install --target .pylibs numpy opencv-python-headless scipy pillow imageio-ffmpeg
export PYTHONPATH=$PWD/.pylibs

python anim/prep_assets.py          # разбор картинки на слои  (~3 с)
python anim/render.py --preview 9,17,18.4,29   # PNG-стиллы для проверки
python anim/render.py               # 1080x1620, полный рендер 33 с (≈5-6 мин)
python anim/render.py --width 1080 --height 1920 --out anim/media/living_painting_9x16.mp4  # 9:16
python anim/audio.py                # партитура
ffmpeg -i anim/media/<render>.mp4 -i anim/media/score.wav \
       -c:v copy -c:a aac -b:a 192k -shortest anim/media/<final>.mp4
```

Все параметры сценарного тайминга — в начале `render.py` (`EYE_OPEN`,
`ROOK_LIFT/GO/LAND`, `CAMERA`, `TITLE_IN`).
