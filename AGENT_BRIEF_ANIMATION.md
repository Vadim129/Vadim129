## 3. Жёсткие правила

- Всё локально: Python + numpy/OpenCV + ffmpeg. **Никаких** SaaS-аниматоров, «AI video» API, облачных
  рендеров.
- Не менять лицо/личность реального человека, не «улучшать» его генеративно. Фото — это фото: аккуратная
  карточка, кроп, рамка, свет. Не перерисовывать.
- Не брать чужие шрифты/музыку из интернета без разрешения; шрифты — Google Fonts (OFL), музыка — от
  заказчика.
- Не терять исходники: всё, что сгенерировано скриптами, должно пересобираться одной командой.
- Не сдавать «скрипт» вместо результата. Результат — воспроизводимый MP4.
- Коммитить и пушить только в рабочую ветку сессии. Большие медиа — в `.gitignore`, если репозиторий не
  предназначен для них.
- Ответ пользователю — по-русски, коротко, с ссылками на файлы.

## 5. Пайплайн

### Шаг 0. Аудит материалов (5 минут, экономит часы)

```bash
"$FF" -hide_banner -i assets/track.mp3 2>&1 | grep -E "Duration|Stream"
python3 - <<'PY'
import cv2, glob
for f in sorted(glob.glob("assets/*.jpg")):
    im = cv2.imread(f)
    print(f, im.shape if im is not None else "FAIL")
PY
```

Записать в заметки: длительность и частота трека, разрешения картинок, где лицо/голова, есть ли готовый
фон. Всё, что меньше 900 px по короткой стороне, в 1080-кадре будет мылом — либо кропать плотнее, либо
апскейлить с `INTER_CUBIC` и не ставить на весь экран.

### Шаг 1. Разбор музыки

Нужно: длительность, BPM, структура (вступление / вокал / брейк / финал), список онсетов для синхронизации.
Код — §7.5.

Практика: акценты ставь не на каждый онсет, а на **сильные доли**; движение персонажа начинается на
0,05–0,10 с **раньше** бита (иначе воспринимается как опоздание), а приземление/удар — точно по биту.

### Шаг 2. Подготовка ассетов

- **Вырезание персонажа.** Пробуй по порядку: (1) готовый PNG с альфой; (2) `rembg`/`backgroundremover`,
  если доступны; (3) ручная маска по цвету фона (только однотонный фон!); (4) **отказ от вырезания** —
  карточка с рамкой (так делали с фото: кремовая рамка + скругление + мягкая тень). Четвёртый вариант
  почти всегда выглядит дороже, чем рваный край.
- **Проверка края:** собери превью 1:1 на нейтральном фоне и посмотри при 100%. Ореолы, «съеденные»
  волосы, дырки в одежде — брак. Не лечи grabCut'ом: он течёт.
- **Размеры:** самый крупный план персонажа — не больше 85% высоты кадра; дальний — не меньше 300 px.
- **Разделение на слои:** тело / голова / глаза / веки / рот / руки (2) / ноги (2) / хвост / уши / волосы.
  Каждый слой — отдельный PNG с прозрачностью, **одинакового масштаба**, чтобы пивоты были в одной системе
  координат.

### Шаг 3. Риг

Риг = список слоёв с пивотами и z-порядком. Пивот — точка вращения в координатах **своего** PNG:
плечо у руки, шея у головы, бедро у ноги, центр у глаза.

Формат данных (можно держать прямо в коде, можно в `rig.json`):

```json
{
  "size": [1000, 1400],
  "ground": 1240,
  "parts": [
    {"name": "leg_l",  "file": "leg_l.png",  "pos": [455, 1100], "pivot": [48, 12],  "z": 1},
    {"name": "leg_r",  "file": "leg_r.png",  "pos": [545, 1100], "pivot": [48, 12],  "z": 1},
    {"name": "body",   "file": "body.png",   "pos": [500, 1115], "pivot": [210, 330], "z": 2},
    {"name": "arm_l",  "file": "arm_l.png",  "pos": [300, 830],  "pivot": [30, 22],  "z": 3},
    {"name": "arm_r",  "file": "arm_r.png",  "pos": [700, 830],  "pivot": [30, 22],  "z": 4},
    {"name": "head",   "file": "head.png",   "pos": [500, 790],  "pivot": [260, 420], "z": 5},
    {"name": "eye_l",  "file": "eye_l.png",  "pos": [425, 690],  "pivot": [40, 45],  "z": 6},
    {"name": "eye_r",  "file": "eye_r.png",  "pos": [575, 690],  "pivot": [40, 45],  "z": 6},
    {"name": "mouth",  "file": "mouth.png",  "pos": [500, 780],  "pivot": [60, 40],  "z": 7}
  ]
}
```

Правила рига:

- Позиции — в «пространстве персонажа» (например, 1000×1400), а не в пикселях кадра. В кадр персонаж
  ставится одним глобальным трансформом (позиция, масштаб, поворот).
- Порядок слоёв фиксирован `z`; глаза/рот всегда поверх головы, дальняя рука — под телом, ближняя — над.
- Один слой может иметь несколько состояний (рот закрыт/открыт, глаз открыт/закрыт) — это отдельные PNG,
  переключаемые по времени; так анимация читается лучше, чем растягивание одного спрайта.
- Если персонаж — **одна плоская картинка** (нет слоёв): режим `--flat` (см. §6.6): squash & stretch,
  покачивание, «дыхание» через вертикальную синусоиду + лёгкая волна remap. Это минимум, но не финал:
  заказчику честно скажи, что для полноценной лицевой анимации нужны слои.

### Шаг 4. Анимация

Базовый набор, ниже которого не опускаться (даже для 5-секундного ролика):

| Что | Как | Зачем |
|---|---|---|
| Дыхание | `sy = 1 + 0.02*sin(2πt/2.6)`, `sx = 1 - 0.015*sin(...)`, грудь/тело | персонаж не «стеклянный» |
| Моргание | масштаб глаза по `sy` до 0,08 за 0,06–0,08 с, 2–4 раза за 10 с, нерегулярно | мгновенно оживляет |
| Взгляд | смещение зрачков/глаз на ±3–6 px, с паузами | «думает» |
| Жест | рука: поворот от плеча 0→70°, качание кистью, возврат; 1,2–2 с | действие |
| Наклон головы | ±3–6°, с задержкой 0,1 с от корпуса | вторичная анимация |
| Squash & stretch | перед прыжком `sy 0.88/sx 1.08`, в полёте `sy 1.10`, на посадке снова сжатие | вес |
| Шаг/прыжок | смещение корпуса по Y + тень (масштаб и прозрачность) | контакт с землёй |
| Реакция на бит | короткий импульс масштаба/наклона на сильных долях | «в ритме» |

Тайминги и кривые:

- Вход — `ease_out` (быстро тронулся, мягко доехал), выход — `ease_in`, удар — `back_out` с перелётом
  5–10%.
- Всё, что длится дольше 0,4 с, должно иметь ускорение/замедление. Линейно двигается только механический
  объект.
- Держи паузы: 15–25% времени персонаж почти неподвижен (только дыхание/моргание). Без пауз движение
  превращается в шум.
- Вторичная анимация с задержкой: уши/хвост/волосы повторяют движение корпуса через 2–4 кадра, с
  затуханием.
- Цикл (idle, шаг) должен сшиваться: значение и производная на концах совпадают.

### Шаг 5. Сцена и композитинг

- Фон: 2–3 слоя с параллаксом (дальний двигается на 20–40% от камеры, ближний — на 110–130%).
- Земля: контактная тень эллипсом, мягкая (гаусс 12–25 px), альфа 0,18–0,30, сжимается при прыжке.
- Свет: тёплый «лик» в одном углу, виньетка 12–20% по краям, зерно 2–4% — три вещи, которые убирают
  ощущение «сгенерировано в скрипте».
- Камера: медленный дрейф/наезд 2–6% за сцену. Никогда не тряска без причины.
- Переходы: кросс-диссолв 0,4–0,7 с с «промывкой» бумагой/светом; не больше одного типа перехода на клип.
- Текст: шрифт с поддержкой кириллицы; цифры проверяй отдельно (некоторые вариативные шрифты ломают
  «5» и «1»). Кегль заголовка 220–320 px, подписи 56–72 px, межстрочный 1,15–1,25. Текст появляется
  построчно, с задержкой 0,25–0,45 с, с лёгким подъёмом 20–30 px.

### Шаг 6. Рендер

- Собирай кадр в numpy `uint8` BGR 1080×1920, пиши в ffmpeg через stdin (код — §7.1). Никаких
  промежуточных PNG-секвенций на 3000 кадров (медленно и занимает гигабайты).
- Сначала **превью**: 6–8 стоп-кадров в ключевых моментах (`--preview 2,6,12,18,24,30`). Смотри глазами,
  исправляй, только потом полный рендер.
- Полный рендер 38 с ≈ 4–5 минут на 2 ядрах. Ставь таймаут 15–20 минут, не 60 секунд.
- Если рендер упал посередине — не начинай заново «на всякий случай»: рендери чанками и склеивай
  (`-f concat`), либо перезапускай с `--start`.

### Шаг 7. Музыка

```bash
"$FF" -y -i media/silent.mp4 -i assets/track.wav \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest \
  -movflags +faststart media/final.mp4
```

- `-shortest` обязателен, иначе хвост тишины/обрыв.
- Длительность видео = длительность музыки. Если трек 37,9 с — таймлайн заканчивается на 37,9, а не на

- Проверь уровень: `-af volumedetect` → `max_volume` не выше 0 dB, `mean_volume` −14…−18 dB.

### Шаг 8. QC

- Контактный лист из 12–16 кадров (§7.6) — глазами, не «на веру».
- Проверить: длительность, оба потока, fps, размер, первые/последние кадры, отсутствие чёрных кадров,
  отсутствие обрезанного текста, отсутствие «двойных» лиц и артефактов вырезания.
- Проверить, что персонаж **реально меняется** от кадра к кадру: разница кадров 0 и 30 не должна быть
  только сдвигом фона.
- Проверить звук на первых и последних 2 секундах (щелчки, обрыв).

## 6. Анимация подробнее

### 6.1. Модель времени

Всё считается функцией `t` (секунды): `frame = render(t)`. Никакого накопления состояния — иначе
невозможен параллельный рендер и перемотка.

```
render(t) -> scene(t) -> character(t) -> pose(t) -> { part: (pos, rot, scale, alpha) }
```

### 6.2. Ключевые кадры

Дорожка = список `(время, значение)`. Между ними — easing, не линейная интерполяция:

```python
def smooth(x):      return x * x * (3 - 2 * x)              # мягко в обе стороны
def ease_out(x):    return 1 - (1 - x) ** 3                  # вход в движение
def ease_in(x):     return x ** 3                            # торможение
def back_out(x, k=1.9): return 1 + (k + 1) * (x - 1) ** 3 + k * (x - 1) ** 2  # перелёт
```

Правило: у каждого движения есть **подготовка** (antecipation, 3–6 кадров в противоположную сторону),
**действие**, **доводка** (overshoot + возврат).

### 6.3. Процедурные слои

Поверх ключей добавляются синусоиды с разными периодами и фазами: дыхание (2,4–3,2 с), покачивание
(3,5–5 с), микро-дрожание (0,15 с, амплитуда 0,3 px). Сумма трёх частот разной природы = «живость».

### 6.4. Синхронизация с музыкой

```python
def pulse(t, beats, decay=7.0):
    """1.0 сразу после бита, затухает к 0."""
    k = bisect.bisect_right(beats, t)
    if k == 0:
        return 0.0
    return math.exp(-decay * (t - beats[k - 1]))
```

Применять к: масштабу тела (0→+2%), наклону головы (±1,5°), яркости фона (+4%), тени. Ровно один
импульс на сильную долю, не на каждый удар.

### 6.5. Вторичная анимация

Уши, хвост, волосы, шарф: значение = сглаженное движение корпуса с задержкой `d` кадров и затуханием
0,6–0,8. Реализуется как `Track` по уже посчитанной позе на `t - d`, либо как пружина:

```python
def spring(x, v, target, k=90.0, damp=12.0, dt=1 / 30):
    a = k * (target - x) - damp * v
    v += a * dt
    return x + v * dt, v
```

### 6.6. Режим «плоская картинка» (одна PNG без слоёв)

1. Squash & stretch: `sy` 1±0.04 на дыхании, `sx` обратно пропорционально (сохранение объёма).
2. Покачивание: поворот ±2,5° вокруг низа картинки.
3. Вертикальный боб: ±6 px, период 2,6 с.
4. «Дыхание» картинки: `cv2.remap` с волной `dy = 2*sin(x/90 + t*2)` — лёгкое колыхание контура.
5. Пульс на бит.

Это читается как «персонаж дышит», но не как «говорит/машет». Ограничение проговорить заказчику заранее.

### 7.2. Альфа-композитинг

```python
import numpy as np

def composite(dst, src, x, y):
    """Накладывает BGRA-спрайт src в BGR-кадр dst с левым верхним углом (x, y)."""
    h, w = src.shape[:2]
    x0, y0 = max(0, x), max(0, y)
    x1, y1 = min(dst.shape[1], x + w), min(dst.shape[0], y + h)
    if x1 <= x0 or y1 <= y0:
        return
    sub = src[y0 - y:y1 - y, x0 - x:x1 - x]
    a = sub[..., 3:4].astype(np.float32) * (1.0 / 255.0)
    roi = dst[y0:y1, x0:x1].astype(np.float32)
    dst[y0:y1, x0:x1] = (sub[..., :3].astype(np.float32) * a + roi * (1.0 - a)).astype(np.uint8)
```

Тень рисуется **до** спрайта в тот же ROI, иначе получится серый прямоугольник.

### 7.3. Трансформ слоя (пивот → позиция)

```python
import cv2
import numpy as np

def blit(canvas, img, pivot, pos, angle=0.0, scale=1.0):
    """Кладёт BGRA-слой в canvas так, чтобы точка pivot оказалась в pos."""
    h, w = img.shape[:2]
    m = cv2.getRotationMatrix2D((float(pivot[0]), float(pivot[1])), float(angle), float(scale))
    m[0, 2] += float(pos[0]) - pivot[0]
    m[1, 2] += float(pos[1]) - pivot[1]

    corners = np.array([[0, 0], [w, 0], [w, h], [0, h]], np.float32).reshape(-1, 1, 2)
    pts = cv2.transform(corners, m).reshape(-1, 2)
    x0 = max(0, int(np.floor(pts[:, 0].min())))
    y0 = max(0, int(np.floor(pts[:, 1].min())))
    x1 = min(canvas.shape[1], int(np.ceil(pts[:, 0].max())) + 1)
    y1 = min(canvas.shape[0], int(np.ceil(pts[:, 1].max())) + 1)
    if x1 <= x0 or y1 <= y0:
        return

    m[0, 2] -= x0
    m[1, 2] -= y0
    roi = cv2.warpAffine(img, m, (x1 - x0, y1 - y0), flags=cv2.INTER_LINEAR,
                         borderMode=cv2.BORDER_CONSTANT, borderValue=(0, 0, 0, 0))
    a = roi[..., 3:4].astype(np.float32) * (1.0 / 255.0)
    dst = canvas[y0:y1, x0:x1].astype(np.float32)
    canvas[y0:y1, x0:x1] = (roi[..., :3].astype(np.float32) * a + dst * (1.0 - a)).astype(np.uint8)
```

### 7.4. Дорожка ключевых кадров

```python
def smooth(x):
    return x * x * (3 - 2 * x)


class Track:
    """Кусочная интерполяция между (t, value); ease: linear | smooth | out | in."""

    def __init__(self, keys, ease="smooth"):
        self.keys = sorted(keys)
        self.ease = ease

    def __call__(self, t):
        ks = self.keys
        if not ks:
            return 0.0
        if t <= ks[0][0]:
            return ks[0][1]
        if t >= ks[-1][0]:
            return ks[-1][1]
        for (t0, v0), (t1, v1) in zip(ks, ks[1:]):
            if t0 <= t <= t1:
                u = (t - t0) / max(1e-6, t1 - t0)
                if self.ease == "smooth":
                    u = smooth(u)
                elif self.ease == "out":
                    u = 1 - (1 - u) ** 3
                elif self.ease == "in":
                    u = u ** 3
                return v0 + (v1 - v0) * u
        return ks[-1][1]
```

### 7.5. Онсеты и BPM

```python
import subprocess
import numpy as np


def decode_audio(path, ffmpeg, sr=22050):
    raw = subprocess.run(
        [ffmpeg, "-v", "error", "-i", path, "-ac", "1", "-ar", str(sr), "-f", "f32le", "-"],
        capture_output=True, check=True).stdout
    return np.frombuffer(raw, np.float32)


def onsets(x, sr=22050, hop=512, win=2048, thresh=1.6):
    """Спектральный поток → пики. Возвращает времена в секундах."""
    n = 1 + (len(x) - win) // hop
    idx = np.arange(win)[None, :] + hop * np.arange(n)[:, None]
    spec = np.abs(np.fft.rfft(x[idx] * np.hanning(win), axis=1))
    flux = np.maximum(0.0, np.diff(np.log1p(spec), axis=0)).sum(axis=1)
    flux = (flux - flux.mean()) / (flux.std() + 1e-6)
    peaks = [i for i in range(1, len(flux) - 1)
             if flux[i] > thresh and flux[i] >= flux[i - 1] and flux[i] > flux[i + 1]]
    out, last = [], -1e9
    for i in peaks:
        t = (i + 2) * hop / sr
        if t - last > 0.12:
            out.append(round(t, 3))
            last = t
    return out
```

BPM оценивай по медиане интервалов между онсетами: `bpm = 60 / median(diff(onsets))`, затем округли до
целого и проверь, что 4 удара укладываются в фразу.

### 8.1. Автоматическая проверка «персонаж действительно двигается»

Глазами можно обмануться. Сравни движение **внутри** области персонажа и **снаружи** (фон/камера):
если в персонаже разница не больше, чем в фоне, — двигается только камера.

```python
import cv2
import numpy as np
import subprocess


def frame_at(video, t, ff, tmp="tmp/_m.png"):
    subprocess.run([ff, "-y", "-hide_banner", "-loglevel", "error",
                    "-ss", str(t), "-i", video, "-frames:v", "1", tmp], check=True)
    return cv2.imread(tmp).astype(np.float32)


def motion_ratio(video, ff, box, t0=1.0, step=0.5, n=6):
    """box = (x0, y0, x1, y1) — область персонажа. Вернёт (движение в персонаже, движение фона)."""
    base = frame_at(video, t0, ff)
    inside, outside = [], []
    for k in range(1, n + 1):
        cur = frame_at(video, t0 + k * step, ff)
        d = np.abs(cur - base).mean(axis=2)
        x0, y0, x1, y1 = box
        inside.append(d[y0:y1, x0:x1].mean())
        mask = np.ones(d.shape, bool)
        mask[y0:y1, x0:x1] = False
        outside.append(d[mask].mean())
    return float(np.mean(inside)), float(np.mean(outside))
```

Норма: движение в персонаже минимум в **1,5–2 раза** выше фонового. Если меньше — добавь жесты, наклоны,
шаг; не крути камеру сильнее.

## 9. Грабли (мы на них уже наступали — не повторяй)

**OpenCV**

- `cv2.line / circle / ellipse` с кортежем из `numpy.float32` → `Scalar value ... not numeric`. Приводи
  к `int`/`float` явно.
- В OpenCV 5 `cv2.ellipse` требует угол как `int` и цвет как 4-float кортеж для BGRA.
- Срез вида `arr[:, :, :3]` — не contiguous; `cv2.circle` падает с `Layout of the output array img is
  incompatible`. Делай `np.ascontiguousarray(...)`, рисуй, возвращай обратно.
- Спрайты для композитинга — **BGRA**, не RGBA. Иначе красный и синий меняются местами (текст становится
  синим).
- Тень, нарисованная после спрайта, даёт серый прямоугольник. Сначала размытая тень, затем спрайт.

**PIL / шрифты**

- `features=["lnum"]` требует libraqm; без неё — исключение. Для цифр бери шрифт, где они уже нормальные
  (Playfair Display), не Cormorant Garamond (он рисует «5ı»).
- Ширина текста = `max(textlength, bbox_width)`; если считать только по bbox, буквы наезжают друг на друга
  (у скриптовых шрифтов выносные элементы выходят за advance).

**ffmpeg / bash**

- В образе нет `ffprobe` — только `ffmpeg -i` в stderr.
- `-shortest` забыт → видео длиннее музыки, хвост тишины.
- `timeout 60` на полный рендер → обрыв на середине. Ставь 900–1800 с.
- В инструментах с параметром `cwd` не пиши `cd X && cmd` в поле `cwd` — это не shell.
- Не запускай долгий процесс через bash-таймаут: используй фоновый запуск и жди по логу/порту.

**Код и файлы**

- Никогда не патчи `str.replace`-ом большой сгенерированный файл, если «старый» фрагмент может дойти до
  конца файла: получишь дублирование в сотни тысяч строк. Перезаписывай модуль целиком.
- Держи `prep.py` идемпотентным: повторный запуск должен давать те же ассеты.
- Не коммить медиа в git без необходимости: `.gitignore` для `media/*.mp4`, `tmp/`, `*.wav`.

**Анимация**

- Только камера — не анимация. Заказчик это замечает первым.
- Линейные переходы и одинаковые интервалы читаются как «слайд-шоу».
- Слишком частые моргания (чаще 1 раза в 2 с) выглядят как тик.
- Персонаж, приклеенный к центру кадра на всё время, — скучно; смещай по правилу третей, меняй крупность.
- Текст, который появляется одновременно с движением, не читается: сначала движение, через 0,2 с — текст.
