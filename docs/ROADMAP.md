# План развития

## Шаг 1 — сделано (v0.1)

* 6 материалов, 5 бумаг, 5 палитр, настроение, плотность
* 16 сцен, человек по суставам, руки через обратную кинематику
* анализ трека на устройстве: БПФ, поток ударов, темп, сетка долей, энергия
* автомат-раскладка + сценарий словами, привязка к долям, финал
* камера с дыханием и качанием по ударам, переворот страницы дневника
* экспорт mp4/webm со звуком в реальном времени + кадр PNG

## Шаг 2 — сделано (v0.2)

1. **Фото в кадр** — `makePhotoScene`: полароид с рукописной рамкой, скотчем, тенью,
   подписью и мелочами вокруг (сердечки, звёздочки, штампик). ✅
2. **Обводка** — `src/image.js`: яркость → размытие → Собель → порог по Оцу → прореживание
   (НМС или скелет Зонга-Суня для штриховых рисунков) → цепочки линий → склейка обрывков →
   упрощение Дугласа-Пекера. Сцена `makeTraceScene` рисует линии по очереди сверху вниз,
   тени — штриховкой. Автовыбор режима «линии/края», ползунок детализации. ✅
3. **Персонаж из рисунка** — сложнее: ручная разметка суставов поверх картинки (6 точек),
   дальше тот же скелет, что у `figure`, и картинка привязывается к костям. Отложено.
4. **Материалы**: восковые мелки, цветные фломастеры, гуашь. ✅ (акварель, штампы — дальше)
5. **Сцены**: +снег, костёр, дорога, доброе утро (+сцены из картинок) = 20 рисованных. ✅
6. **Android**: `package.json`, `capacitor.config.json`, `build-www.mjs`, `android/README.md`,
   сохранение в «Документы» через `src/native.js`. ✅ (осталось собрать APK на машине с Android Studio)

## Шаг 3 — сделано (v0.3)

* **Текст трека — Whisper на устройстве** ✅ `src/whisper.js`: transformers.js (ONNX), модели
  tiny/base/small в `*_timestamped`-варианте (дают время по каждому слову), WebGPU с откатом
  на процессор, 16 кГц. **Модель tiny (44 МБ), библиотека и wasm-движок вложены в приложение**
  (`models/`, `vendor/`) — распознавание работает без интернета, в том числе в APK.
  base/small докачиваются по желанию.
* **Сценарий по словам** ✅ словарь «слово → сцена» (`WORD_SCENES`, 20 сцен) + притягивание
  времени к долям трека. Не ИИ, зато мгновенно.
* **Дальше по ИИ:** LLM в браузере (WebLLM/Qwen) — сценарий по смыслу, а не по словарю;
  облачная LLM — сочинение новых сцен; генерация фонов платная, по умолчанию не нужна.

## Шаг 4 — сделано (v0.3–0.4)
